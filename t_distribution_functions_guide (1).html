scipy.stats.t 함수 완전정복

t분포 곡선 위에서 pdf, cdf, sf, ppf, isf, interval, stats가 각각 무엇을 구하는가

같은 곡선, 다른 질문 — 그림으로 구별하고 손계산·코드로 확인한다

0t분포 리마인드

t분포는 표준정규분포 Z를 자유도 k인 카이제곱분포의 제곱근으로 나눈 값이 따르는 분포다: \(t=Z/\sqrt{\chi^2_{(k)}/k}\). 모표준편차 대신 표본표준편차 s를 쓸 때 생기는 추가적 불확실성 때문에 정규분포보다 꼬리가 두껍고, 자유도(df)가 커질수록 표준정규분포에 가까워진다.

17개 함수 전체 지도

모든 함수는 "가로축(t값)"과 "세로축 또는 면적(확률)" 사이를 오가는 변환이다. 방향이 핵심이다: t값 → 확률로 가는 함수(pdf, cdf, sf)와, 확률 → t값으로 거꾸로 가는 함수(ppf, isf)로 나뉜다.

함수입력출력방향한 줄 의미
pdf(x, df)t값밀도(높이)t → 높이그 지점의 곡선 높이(확률이 아님)
cdf(x, df)t값누적확률t → 확률P(T ≤ x), 왼쪽부터 누적 면적
sf(x, df)t값꼬리확률t → 확률P(T > x) = 1-cdf(x), 오른쪽 꼬리 면적
ppf(q, df)누적확률 qt값확률 → tcdf의 역함수, "누적확률 q가 되는 t는?"
isf(q, df)꼬리확률 qt값확률 → tsf의 역함수, "오른쪽 꼬리확률 q가 되는 t는?"
interval(a, df)중심확률 a(하한,상한)확률 → t 구간중심 a를 포함하는 대칭 구간, ppf를 좌우로 묶음
stats(df,'mv')자유도(평균,분산)분포 → 요약값곡선 하나가 아닌 분포 전체의 요약 통계
ppf(0.975, df)와 isf(0.025, df)는 항상 같은 t값을 돌려준다. "누적확률이 97.5%인 지점"과 "오른쪽 꼬리확률이 2.5%인 지점"은 정확히 같은 점이기 때문이다. 이 값이 바로 α=0.05 양측검정의 임계값(t 0.025)이다.

2pdf(x, df) — 확률밀도함수

2.1 원리

t=x 지점에서 곡선의 높이(밀도)를 반환한다. 이산변수의 "확률"과 달리 연속변수의 pdf 값 자체는 확률이 아니며, 구간에 대해 적분해야 확률이 된다는 점이 핵심이다. 실무에서는 특정 지점의 상대적 가능성을 비교하거나 곡선 자체를 그릴 때 사용한다.

\[ f(t;k) = \frac{\Gamma\left(\frac{k+1}{2}\right)}{\sqrt{k\pi}\,\Gamma\left(\frac{k}{2}\right)}\left(1+\frac{t^2}{k}\right)^{-\frac{k+1}{2}} \]

2.2 손계산 예제

[문제] df=10일 때 t=0에서의 pdf 값은? [Step1] t=0이면 공식의 (1+t²/k) 항이 1이 되어 계산이 단순화됨 [Step2] f(0;10) = Γ(5.5) / (√(10π) * Γ(5)) [Step3] Γ(5)=4!=24, Γ(5.5)≈52.34, √(10π)≈5.605 [Step4] f(0;10) = 52.34 / (5.605*24) = 52.34/134.5 = 0.389 [결론] df=10 t분포는 t=0에서 높이 0.389 (참고: 표준정규분포는 1/√(2π)≈0.399로 이보다 약간 낮음)
Q. pdf(0, df) 값이 df가 커질수록(예: 5→30→∞) 어떻게 변하는가?

3cdf(x, df) — 누적분포함수

3.1 원리

왼쪽 끝(-∞)부터 t=x까지 곡선 아래 면적을 누적한 값, 즉 P(T ≤ x)를 반환한다. pdf를 -∞부터 x까지 적분한 것과 같다.

\[ F(x)=P(T\le x)=\int_{-\infty}^{x} f(t)\,dt \]

3.2 손계산 예제 (근사)

[문제] df=15에서 cdf(1.5, 15) ≈ ? (t분포표 활용) [Step1] t분포표에서 df=15 행을 찾아 t=1.5 근처 값을 확인 [Step2] t(0.10,15)=1.341, t(0.05,15)=1.753 → 1.5는 그 사이 [Step3] 선형보간: (1.5-1.341)/(1.753-1.341) = 0.159/0.412 ≈ 0.386 상단꼬리확률 ≈ 0.10 - 0.386*(0.10-0.05) = 0.0807 [Step4] cdf(1.5,15) = 1 - 0.0807 ≈ 0.919 (scipy 정확값: 0.9273) [결론] P(T≤1.5) ≈ 0.92, 즉 t=1.5보다 작은 값이 나올 확률이 약 92%
t분포표는 이산적인 몇 개 확률(0.10, 0.05, 0.025...)만 제공하므로 정확한 cdf 값은 선형보간으로도 오차가 있다. 실전에서는 scipy.stats.t.cdf()로 정확히 계산하는 것이 표준이다.
Q. cdf(x, df)의 값이 0.5라면 x는 어떤 값인가?

4sf(x, df) — 생존함수(우측 꼬리확률)

4.1 원리

t=x부터 오른쪽 끝(+∞)까지의 면적, 즉 P(T > x)를 반환한다. 정의상 sf(x) = 1 - cdf(x)이지만, x가 매우 클 때 1-cdf(x)는 부동소수점 정밀도 손실(1에 아주 가까운 수를 빼는 문제)이 생길 수 있어 sf를 직접 계산하는 것이 더 정확하다.

\[ S(x)=P(T> x)=1-F(x)=\int_{x}^{\infty} f(t)\,dt \]

4.2 가설검정에서의 실전 활용 — p-value 계산

[문제] 단일표본 t검정: n=16, t통계량=2.4, df=15. 단측검정(H1: μ>μ0)의 p-value는? [Step1] 단측(오른쪽) 검정이므로 p-value = P(T > 2.4) = sf(2.4, 15) [Step2] scipy 계산 결과 sf(2.4,15) ≈ 0.0149 [Step3] α=.05와 비교: 0.0149 < 0.05 [결론] H0 기각 → 유의한 증가가 있다고 판단
양측검정이라면 p-value = 2 × sf(|t|, df)로 계산한다. 관측된 t값이 어느 쪽 꼬리에 있든 절댓값을 취해 오른쪽 꼬리 면적을 구하고 2배 하면 된다.
Q. 양측 t검정에서 |t|=2.5, df=20일 때 p-value를 구하는 올바른 식은?

5ppf(q, df) / isf(q, df) — 역함수(임계값 찾기)

5.1 원리 — cdf·sf의 반대 방향

cdf와 sf는 "t값을 알 때 확률을 구하는" 함수인 반면, ppf(percent point function)와 isf(inverse survival function)는 확률을 알 때 t값을 역산한다. 검정에서 기각역의 경계(임계값)를 구할 때 필수적으로 사용한다.

\[ \text{ppf}(q,k) = F^{-1}(q) \quad \text{("누적확률이 } q\text{인 } t\text{는?")} \] \[ \text{isf}(q,k) = S^{-1}(q) = F^{-1}(1-q) \quad \text{("오른쪽 꼬리확률이 } q\text{인 } t\text{는?")} \]

5.2 손계산 예제 — 양측검정 임계값 구하기

[문제] df=18, α=.05 양측검정의 임계값(기각역 경계)을 구하시오 [Step1] 양측검정이므로 유의수준을 반으로 나눔: α/2 = 0.025 [Step2] 방법1: ppf(1-0.025, 18) = ppf(0.975, 18) [Step3] 방법2: isf(0.025, 18) — 오른쪽 꼬리 확률이 0.025인 지점 [Step4] t분포표 df=18 행에서 확인: t(0.025,18) = 2.101 [결론] 기각역: t < -2.101 또는 t > +2.101 (두 방법 모두 동일한 값 2.101을 반환)
Q. 단측검정(왼쪽 꼬리)으로 α=.05, df=12일 때 기각역의 경계값을 구하는 올바른 코드는?

6interval(alpha, df) — 중심 신뢰구간

6.1 원리

중심에서 확률 α(예: 0.95)를 포함하는 대칭 구간의 (하한, 상한)을 한 번에 반환한다. 내부적으로는 ppf((1-α)/2)와 ppf(1-(1-α)/2)를 각각 계산해 묶어주는 것과 같다.

\[ \text{interval}(\alpha, k) = \left(F^{-1}\!\left(\tfrac{1-\alpha}{2}\right),\ F^{-1}\!\left(\tfrac{1+\alpha}{2}\right)\right) = \left(-t_{(1-\alpha)/2},\ +t_{(1-\alpha)/2}\right) \]

6.2 손계산 예제 — 평균의 95% 신뢰구간

[문제] n=20, x̄=52, s=8. 모평균의 95% 신뢰구간을 구하시오 [Step1] df = n-1 = 19, t_(0.025,19) = interval(0.95,19)의 경계값 = 2.093 [Step2] SE = s/√n = 8/√20 = 8/4.472 = 1.789 [Step3] 오차범위 = t * SE = 2.093 * 1.789 = 3.745 [Step4] 신뢰구간 = x̄ ± 오차범위 = 52 ± 3.745 = (48.26, 55.75) [결론] "모평균은 95% 신뢰수준에서 48.26~55.75 사이에 있다"고 추정
stats.t.interval()은 표준t분포(위치 0, 척도 1) 기준의 구간만 반환한다. 실제 평균의 신뢰구간을 구하려면 x̄ + 반환값 × SE 형태로 직접 변환하거나, loc과 scale 파라미터에 x̄와 SE를 넣어 호출해야 한다.
Q. interval(0.90, 25)는 어떤 값들을 반환하는가?

7stats(df, moments='mv') — 분포의 요약통계

7.1 원리

다른 함수들이 "곡선 위 한 점 또는 한 구간"에 대한 값이라면, stats()는 분포 전체를 요약하는 통계량(평균, 분산, 왜도, 첨도)을 반환한다. moments 인자로 어떤 통계량을 받을지 선택한다('m'=평균, 'v'=분산, 's'=왜도, 'k'=첨도).

\[ E(T) = 0\ (df>1) \qquad Var(T) = \frac{k}{k-2}\ (df>2) \]

7.2 손계산 예제 — 분산이 df에 따라 어떻게 변하는가

[문제] df=5, df=10, df=100일 때 t분포의 분산을 각각 계산하시오 [df=5] Var = 5/(5-2) = 5/3 = 1.667 [df=10] Var = 10/(10-2) = 10/8 = 1.25 [df=100] Var = 100/(100-2) = 100/98 = 1.02 [결론] df가 커질수록 분산이 표준정규분포의 분산(=1)에 점점 가까워진다 — 꼬리가 얇아지는 것과 같은 현상
df ≤ 2이면 분산이 정의되지 않는다(무한대로 발산). df ≤ 1이면 평균조차 정의되지 않는다(코시분포와 동일해짐). 실무 데이터에서는 표본크기가 매우 작을 때(n=2, 3) 특히 주의해야 한다.
Q. df=4인 t분포의 분산은?

8Python 실전 코드 종합

# 7개 함수 한 번에 확인 from scipy import stats df = 10 print("pdf(0,10) :", stats.t.pdf(0, df)) # 중심 밀도 print("cdf(2,10) :", stats.t.cdf(2, df)) # P(T<=2) print("sf(2,10) :", stats.t.sf(2, df)) # P(T>2) print("ppf(0.975,10) :", stats.t.ppf(0.975, df)) # 양측 alpha=.05 임계값 print("isf(0.025,10) :", stats.t.isf(0.025, df)) # 위와 동일한 값 print("interval(.95,10):", stats.t.interval(0.95, df)) # 95% 중심구간 print("stats(mv) :", stats.t.stats(df, moments='mv'))
# 실전: 평균의 95% 신뢰구간을 직접 구하기 (loc, scale 활용) n, xbar, s = 20, 52, 8 se = s / (n ** 0.5) ci = stats.t.interval(0.95, df=n-1, loc=xbar, scale=se) print(f"95% CI: ({ci[0]:.2f}, {ci[1]:.2f})") # 95% CI: (48.26, 55.75) → 6.2 손계산과 일치
# 실전: 양측 t검정의 p-value를 sf로 계산 t_stat, dfree = 2.5, 20 p_value = 2 * stats.t.sf(abs(t_stat), dfree) print(f"p-value = {p_value:.4f}")
ttest_1samp, ttest_ind 같은 고수준 함수는 내부적으로 위 7개 저수준 함수(특히 sf, cdf)를 조합해 t값과 p-value를 계산한다. 저수준 함수를 이해하면 결과를 검증하거나 커스텀 검정을 직접 구현할 때 큰 도움이 된다.

ADP 필기 서술형 완전정복

제28회부터 제37회까지 ADP(데이터분석 전문가) 필기시험 서술형 기출문제 10개 회차를 문제 원문 그대로 제시하고, 계산 문제는 공식 적용 → 수치 대입 → 검산까지 전 과정을 단계별로 풀어내며, 서술형 문제는 채점 포인트를 명확히 구분해 정리한다.

28회 의사결정나무 — 지니 불순도 연산

의사결정나무지니 불순도정보 이득수리 연산형
문제
전체 데이터 10개 중 Pass가 6개, Fail이 4개 있다. 특정 조건 $A$로 분할한 결과, [그룹 1]에는 Pass 5개, Fail 1개 / [그룹 2]에는 Pass 1개, Fail 3개가 속했다.

소문항 1) 분할 전 전체 데이터의 지니 불순도($I_G$)를 구하시오.

소문항 2) 조건 $A$로 분할한 후의 자식 노드들의 가중평균 지니 불순도를 구하고, 정보 이득(Information Gain)을 계산하시오.

단계별 해설

1지니 불순도 공식
$$I_G = 1 - \sum_{i} p_i^2$$
2소문항 1 — 분할 전 전체 불순도

전체 10개 중 Pass 6개($p_{Pass}=6/10$), Fail 4개($p_{Fail}=4/10$):

$$I_G = 1-\left[\left(\frac{6}{10}\right)^2+\left(\frac{4}{10}\right)^2\right] = 1-(0.36+0.16) = \mathbf{0.48}$$
3소문항 2-1 — 그룹별 불순도

그룹 1 (Pass 5, Fail 1, 총 6개):

$$I_{G1} = 1-\left[\left(\frac{5}{6}\right)^2+\left(\frac{1}{6}\right)^2\right] = 1-\frac{26}{36} = \frac{10}{36} \approx 0.278$$

그룹 2 (Pass 1, Fail 3, 총 4개):

$$I_{G2} = 1-\left[\left(\frac{1}{4}\right)^2+\left(\frac{3}{4}\right)^2\right] = 1-\frac{10}{16} = \frac{6}{16} = 0.375$$
4소문항 2-2 — 가중평균 불순도

각 그룹이 전체에서 차지하는 비율(6/10, 4/10)로 가중평균한다.

$$I_{G,split} = \frac{6}{10}\times\frac{10}{36} + \frac{4}{10}\times\frac{6}{16} = \frac{1}{6}+\frac{3}{20} = \frac{19}{60} \approx \mathbf{0.317}$$
5소문항 2-3 — 정보 이득
$$\text{IG} = I_G(\text{분할 전}) - I_{G,split}(\text{분할 후}) = 0.48-0.317 = \mathbf{0.163}$$
정답 요약
소문항 1: $I_G=0.48$  |  소문항 2: 가중평균 불순도 $\approx0.317$, 정보 이득 $\approx0.163$
검산 팁 — 정보 이득이 양수(0.163>0)라는 것은 조건 $A$로 분할했을 때 불순도가 실제로 감소했다는 뜻이며, 의사결정나무는 이 정보 이득이 최대가 되는 분할 조건을 매 노드마다 탐욕적으로 선택한다는 점까지 답안에 덧붙이면 가점 요인이 된다.

29회 서포트 벡터 머신(SVM) 원리

SVM마진슬랙변수이론 서술형
문제
SVM 모델의 구조와 작동 방식에 대해 서술하시오.

소문항 1) '서포트 벡터(Support Vector)'와 '마진(Margin)'의 개념을 서술하시오.

소문항 2) 하드 마진과 소프트 마진의 차이를 오차 허용 관점에서 설명하시오.

모범답안 — 핵심 채점포인트

구분핵심 키워드서술 포인트
소문항 1서포트 벡터결정 경계면(초평면)과 가장 가까이 위치한 데이터 포인트들
마진서포트 벡터와 결정 경계 사이의 거리; SVM은 이 마진을 최대화하는 방향으로 학습
소문항 2하드 마진오차를 전혀 허용하지 않음 → 노이즈에 취약, 과적합 위험
소프트 마진슬랙 변수 $\xi$ 도입 → 약간의 마진 위반(오차) 허용 → 일반화 성능 향상
추천 답안(서술형 예시)
소문항 1: 서포트 벡터란 SVM이 찾은 결정 경계면(초평면)에 가장 근접한 데이터 포인트들을 의미하며, 이 포인트들이 결정 경계의 위치를 실질적으로 결정한다. 마진은 이 서포트 벡터와 결정 경계 사이의 거리이며, SVM의 학습 목표는 바로 이 마진을 최대화하여 새로운 데이터에 대한 일반화 성능을 높이는 것이다.

소문항 2: 하드 마진 SVM은 모든 데이터가 마진 바깥쪽에 정확히 분류되어야 한다는 제약을 걸어 오차를 전혀 허용하지 않는다. 이 때문에 이상치나 노이즈가 있는 데이터에서는 결정 경계가 불안정해지고 과적합 위험이 커진다. 반면 소프트 마진 SVM은 슬랙 변수 $\xi_i\ge0$를 도입해 일부 데이터가 마진을 침범하거나 오분류되는 것을 허용하되, 이 위반 정도에 비례한 페널티를 목적함수에 추가한다. 이를 통해 노이즈에 강건하면서도 일반화 성능이 높은 모델을 만들 수 있다.

30회 나이브 베이즈 확률 연산

나이브베이즈베이즈정리라플라스 스무딩연산+서술형
문제
전체 메일 중 스팸 메일이 40%, 정상 메일이 60%이다. 스팸 메일 중 '대출' 단어가 포함될 확률은 0.8이고, 정상 메일 중 '대출' 단어가 포함될 확률은 0.1이다.

소문항 1) 어떤 메일에 '대출' 단어가 포함되어 있을 때, 이 메일이 스팸 메일일 확률을 베이즈 정리를 이용해 계산하시오.

소문항 2) 학습 데이터에 없던 새로운 단어가 등장했을 때 확률이 0이 되는 현상을 방지하는 기법 명칭과 원리를 쓰시오.

단계별 해설

1주어진 값 정리
기호의미값
$P(\text{스팸})$사전확률0.4
$P(\text{정상})$사전확률0.6
$P(\text{대출}\mid\text{스팸})$가능도0.8
$P(\text{대출}\mid\text{정상})$가능도0.1
2베이즈 정리 적용
$$P(\text{스팸}\mid\text{대출}) = \frac{P(\text{대출}\mid\text{스팸})P(\text{스팸})}{P(\text{대출}\mid\text{스팸})P(\text{스팸})+P(\text{대출}\mid\text{정상})P(\text{정상})}$$
3분자·분모 계산
$$\text{분자} = 0.8\times0.4 = 0.32$$ $$\text{분모} = (0.8\times0.4)+(0.1\times0.6) = 0.32+0.06 = 0.38$$
4최종 계산
$$P(\text{스팸}\mid\text{대출}) = \frac{0.32}{0.38} \approx \mathbf{0.842\ (84.2\%)}$$
정답 요약
소문항 1: $P(\text{스팸}\mid\text{대출})\approx84.2\%$
5소문항 2 — 라플라스 스무딩
추천 답안
명칭은 라플라스 스무딩(Laplace Smoothing)이다. 나이브 베이즈는 각 단어의 조건부확률을 학습 데이터의 빈도 비율로 추정하는데, 학습 데이터에 한 번도 등장하지 않은 단어가 새 데이터에 나타나면 해당 조건부확률이 0이 되어 전체 곱셈 확률(가능도)까지 0이 되어버리는 문제가 생긴다. 라플라스 스무딩은 모든 단어의 등장 빈도수에 작은 상수(보통 1)를 더하고, 분모에는 전체 어휘 수만큼을 보정해줌으로써 어떤 단어의 조건부확률도 정확히 0이 되지 않도록 방지한다.
$\alpha=1$일 때의 라플라스 스무딩 공식: $P(w\mid c) = \dfrac{\text{count}(w,c)+1}{\text{count}(c)+V}$ ($V$: 전체 어휘 수) — 분자·분모에 각각 $+1$, $+V$를 더해 count가 0인 단어도 확률이 0이 되지 않게 한다.

라플라스 스무딩 수치 예제

학습 데이터에서 어휘가 $V=4$개 {대출, 무료, 회의, 안녕}뿐인 아주 작은 스팸 분류기를 학습시켰다고 하자. 각 단어가 스팸/정상 메일에서 등장한 총 횟수는 다음과 같다.

단어스팸에서 등장 횟수정상에서 등장 횟수
대출81
무료50
회의06
안녕25
합계1512

새로 도착한 메일에 "회의"라는 단어가 포함되어 있다. 이 단어는 학습 데이터의 스팸 메일에서 단 한 번도 등장하지 않았다(count=0).

6문제 상황 — 스무딩 없이 계산하면
$$P(\text{회의}\mid\text{스팸}) = \frac{\text{count}(\text{회의},\text{스팸})}{\text{count}(\text{스팸})} = \frac{0}{15} = 0$$
이 메일에 "회의" 외에 스팸을 강하게 암시하는 다른 단어(예: "대출", "무료")가 잔뜩 있어도, 나이브 베이즈는 모든 단어의 조건부확률을 곱해서 가능도를 구하기 때문에 $P(\text{회의}\mid\text{스팸})=0$ 하나가 전체 곱셈 결과를 통째로 0으로 만들어버린다. 즉 다른 증거를 전부 무시하고 "이 메일은 스팸일 확률 0%"라고 잘못 결론 내리게 된다.
7라플라스 스무딩(α=1) 적용

모든 단어의 분자에 $+1$, 분모에는 어휘 수 $V=4$를 더해서 계산한다.

$$P(\text{회의}\mid\text{스팸}) = \frac{\text{count}(\text{회의},\text{스팸})+1}{\text{count}(\text{스팸})+V} = \frac{0+1}{15+4} = \frac{1}{19} \approx \mathbf{0.0526}$$

같은 방식으로 정상 메일 쪽도 계산하면:

$$P(\text{회의}\mid\text{정상}) = \frac{6+1}{12+4} = \frac{7}{16} = \mathbf{0.4375}$$
정답 요약
스무딩 전: $P(\text{회의}\mid\text{스팸})=0$ (전체 가능도를 0으로 만드는 문제 발생)  →  스무딩 후: $P(\text{회의}\mid\text{스팸})=1/19\approx5.26\%$ (0은 아니지만 여전히 작은 값 — "스팸에서는 드문 단어"라는 정보는 유지하면서도 확률이 완전히 죽지는 않음)
그림 30-1. 스무딩 전에는 "회의"의 스팸 조건부확률이 정확히 0이 되어 이 단어 하나가 전체 곱셈 가능도를 0으로 무너뜨린다. 라플라스 스무딩을 적용하면 여전히 작은 값(≈5.3%)이지만 0은 아니게 되어, 다른 단어들의 증거가 계산에 정상적으로 반영될 수 있다.
전체 가능도로 보면 차이가 더 뚜렷하다 — 메일에 "회의"와 "안녕" 두 단어만 있다고 가정하고 $P(\text{회의}\mid\text{스팸})\times P(\text{안녕}\mid\text{스팸})$를 계산하면, 스무딩 전에는 $0\times(\cdots)=\mathbf{0}$ 이지만, 스무딩 후에는 $\frac{1}{19}\times\frac{2+1}{19}=\frac{1}{19}\times\frac{3}{19}\approx\mathbf{0.0083}$ 으로 0이 아닌 값이 나와, 이후 베이즈 정리로 "정상"과 정상적으로 비교할 수 있게 된다.

31회 앙상블 기법 비교

소문항 1) 샘플링 방식과 모델 학습 방식 측면에서 두 기법을 비교하시오.

소문항 2) 오차의 구성요소인 편향(Bias)과 분산(Variance) 관점에서 각각 어떤 것을 줄이는 데 효과적인지 서술하시오.

모범답안 — 핵심 채점포인트

구분배깅(Bagging)부스팅(Boosting)
샘플링 방식복원추출(Bootstrap)로 독립적인 샘플 여러 개 생성이전 모델의 오분류 데이터에 가중치를 부여해 순차 샘플링
학습 방식여러 모델을 병렬(독립적)로 학습이전 모델의 오차를 보완하도록 순차적으로 학습
주로 줄이는 오차분산(Variance) — 평균을 내어 과적합 방지편향(Bias) — 무작위 오차를 점진적으로 줄여나감
추천 답안(서술형 예시)
소문항 1: 배깅은 원본 데이터에서 복원추출(Bootstrap)로 여러 개의 부트스트랩 샘플을 만들고, 각 샘플로 학습된 개별 모델들을 서로 독립적으로 병렬 학습시킨다. 반면 부스팅은 첫 모델을 학습한 뒤, 그 모델이 잘못 예측한(오분류한) 데이터에 더 큰 가중치를 부여해 다음 모델이 그 오차를 중점적으로 학습하도록 순차적으로 모델을 이어붙인다.

소문항 2: 배깅은 서로 독립적으로 학습된 여러 모델의 예측을 평균(또는 다수결)내기 때문에 개별 모델의 변동성이 상쇄되어 분산(Variance)이 감소하고, 이를 통해 과적합을 방지하는 데 효과적이다. 반면 부스팅은 이전 모델이 놓친 오차를 다음 모델이 순차적으로 보정해나가는 구조이므로, 모델 전체의 편향(Bias)을 점진적으로 줄이는 데 효과적이다.

32회 로지스틱 회귀와 손실 함수

로지스틱회귀오즈·로짓MLE수식 서술형
문제
로지스틱 회귀분석의 기본 수학적 개념을 묻는 문제입니다.

소문항 1) 로지스틱 회귀에서 사용하는 '오즈(Odds)'의 정의와 선형 회귀 형태를 만들기 위해 취하는 변환 공식(로짓)을 쓰시오.

소문항 2) 로지스틱 회귀의 손실 함수인 이진 크로스 엔트로피(Binary Cross Entropy) 수식을 쓰고, 이를 최소화하는 방법론의 통계적 명칭을 쓰시오.

단계별 해설

1오즈(Odds)의 정의

성공확률 $p$일 때, 오즈는 "성공확률이 실패확률의 몇 배인가"를 나타낸다.

$$\text{Odds} = \frac{p}{1-p}$$
2로짓(Logit) 변환

오즈에 자연로그를 취하면 $(-\infty,\infty)$ 범위를 갖게 되어 선형결합으로 표현할 수 있다.

$$\text{Logit}(p) = \ln\left(\frac{p}{1-p}\right) = \beta_0+\beta_1X$$
3이진 크로스 엔트로피(BCE) 손실함수
$$L = -\frac{1}{n}\sum_{i=1}^n\left[y_i\ln(\hat{y}_i)+(1-y_i)\ln(1-\hat{y}_i)\right]$$
4최소화 방법론의 통계적 명칭
정답
BCE를 최소화하는 것은 통계학의 최대우도추정법(MLE, Maximum Likelihood Estimation)을 통해 우도(likelihood)를 최대화하는 것과 수학적으로 동일하다 — 음의 로그우도(negative log-likelihood)를 최소화하는 것이 곧 우도를 최대화하는 것이기 때문이다.
$y_i=1$인 데이터는 $\ln(\hat y_i)$ 항만, $y_i=0$인 데이터는 $\ln(1-\hat y_i)$ 항만 손실에 기여하도록 설계되어 있다 — 예측 확률이 실제 레이블과 다를수록(예: 정답이 1인데 $\hat y_i\to0$) 손실이 무한대에 가깝게 커진다는 점까지 서술하면 가점 요인이 된다.

33회 DBSCAN 군집분석 지표

DBSCANEps·MinPts실루엣계수이론+수식형
문제
밀도 기반 군집화 알고리즘인 DBSCAN과 평가 지표에 관한 문제입니다.

소문항 1) DBSCAN의 하이퍼파라미터 2가지를 적고, 핵심 포인트(Core Point)의 판정 기준을 서술하시오.

소문항 2) 비지도 학습의 대표적 평가 지표인 실루엣 계수(Silhouette Coefficient)의 수식적 의미와 좋은 군집의 기준 수치를 쓰시오.

단계별 해설

1DBSCAN의 하이퍼파라미터
파라미터의미
$\text{Eps}\ (\varepsilon)$이웃으로 인정할 반경(거리 임계값)
$\text{MinPts}$핵심 포인트로 인정받기 위한 최소 이웃 점 개수

핵심 포인트(Core Point) 판정 기준: 어떤 점을 중심으로 반경 $\text{Eps}$ 이내에 자기 자신을 포함해 $\text{MinPts}$개 이상의 점이 존재하면 그 점을 핵심 포인트로 판정한다.

2실루엣 계수 수식
$$s = \frac{b-a}{\max(a,b)}$$
기호의미
$a$같은 군집 내 다른 점들과의 평균 거리 (군집 내 응집도)
$b$가장 가까운 다른 군집에 속한 점들과의 평균 거리 (군집 간 분리도)
3기준 수치 해석
$s$ 값 범위의미
$s\to1$군집 내 응집도는 높고 다른 군집과는 멀리 떨어짐 → 군집화가 잘 됨
$s\to0$군집 경계가 모호함 (다른 군집과 거리가 비슷)
$s<0$다른 군집에 더 가까움 → 오분류 가능성
정답 요약
$s$가 1에 가까울수록 좋은 군집화, 0에 가까우면 경계 모호, 음수면 오분류를 의미한다.

34회 분류 임계값(Threshold) 조정 효과

Precision·RecallROC·AUC지표 해석형
문제
비가 올 확률을 예측하는 이진 분류 모델이 있다. 기본 임계값(Threshold)인 0.5를 0.8로 올렸을 때 모델 성능 지표에 미치는 영향을 서술하시오.

소문항 1) 혼동행렬의 정밀도(Precision)와 재현율(Recall)에 미치는 변화를 쓰시오.

소문항 2) 임계값과 무관하게 모델의 전반적인 분류 성능을 측정하는 곡선 지표의 명칭을 쓰시오.

단계별 해설

1임계값 상승(0.5→0.8)의 의미

모델은 예측확률이 임계값 이상일 때만 Positive("비가 온다")로 분류한다. 임계값을 0.8로 올리면 매우 확신할 때만 Positive로 예측하게 되어, Positive로 예측하는 건수 자체가 줄어든다.

2Precision·Recall 공식과 변화 방향
$$\text{Precision} = \frac{TP}{TP+FP}, \qquad \text{Recall} = \frac{TP}{TP+FN}$$
지표변화 방향이유
Precision↑ 상승확실한 경우만 Positive로 예측하므로 예측이 맞을 확률(정밀도)이 높아짐 (FP 감소)
Recall↓ 하락임계값 미달로 실제 Positive인데 Negative로 놓치는 경우(FN)가 늘어남
3임계값 무관 지표
정답
ROC 곡선(Receiver Operating Characteristic Curve)과 그 곡선 아래 면적인 AUC(Area Under the Curve). ROC 곡선은 임계값을 0~1까지 전부 바꿔가며 각 지점에서의 (FPR, TPR)을 그린 곡선이므로, 특정 임계값 하나에 의존하지 않고 모델의 전반적인 분류 성능을 평가할 수 있다.
Precision-Recall 트레이드오프는 임계값 조정의 전형적인 결과다 — "Precision과 Recall은 동시에 높이기 어렵고 한쪽을 높이면 다른 쪽이 낮아지는 경향이 있다"는 문장을 답안에 포함하면 채점 포인트를 더 확실히 챙길 수 있다.

35회 1D CNN 연산 및 클래스 불균형 해결

1D Convolution클래스 불균형SMOTE연산+대안제시형
문제
입력 데이터가 $[2, 4, 1, 3]$이고, 크기가 2인 필터 가중치가 $[1, -1]$이다. 패딩 없이 스트라이드 1로 연산하려 한다.

소문항 1) 1D 합성곱(Convolution) 연산을 수행한 피처 맵의 결과 배열을 구하시오.

소문항 2) 데이터셋에서 양성 클래스가 1%, 음성 클래스가 99%인 클래스 불균형 상황에서 이를 해결할 수 있는 데이터 관점의 기법 2가지를 제시하시오.

단계별 해설

1출력 크기 확인

입력 길이 4, 필터 크기 2, 패딩 0, 스트라이드 1이므로 출력 길이 $=(4-2)/1+1=3$.

2슬라이딩하며 내적 계산

1번째 위치 (입력 [2,4]과 필터 [1,-1]의 내적):

$$(2\times1)+(4\times{-1}) = 2-4 = -2$$

2번째 위치 (입력 [4,1]):

$$(4\times1)+(1\times{-1}) = 4-1 = 3$$

3번째 위치 (입력 [1,3]):

$$(1\times1)+(3\times{-1}) = 1-3 = -2$$
정답 요약
소문항 1: 결과 피처 맵 $=[-2,\ 3,\ -2]$
계산 의미 — 필터 $[1,-1]$은 인접한 두 값의 차이(변화량)를 감지하는 필터다. 입력이 $2\to4$로 급증하면 $-2$, $4\to1$로 급감하면 $+3$(부호가 반대인 이유는 필터가 $[1,-1]$ 순서라서), $1\to3$으로 다시 증가하면 $-2$가 나온다 — 이 필터가 사실상 "1차 미분(변화 감지)" 역할을 한다는 점까지 답안에 덧붙이면 이해도를 보여줄 수 있다.
3소문항 2 — 클래스 불균형 대응 기법
정답
기법원리
오버샘플링 (SMOTE)소수 클래스(양성 1%) 데이터를 합성(interpolation)하여 다수 클래스와 비율을 맞춤 — 기존 소수 클래스 샘플들 사이를 보간해 새로운 가상 샘플을 생성
언더샘플링 (Random Under Sampling)다수 클래스(음성 99%) 데이터를 무작위로 축소하여 비율을 맞춤 — 정보 손실 위험이 있지만 구현이 간단

36회 주성분 분석(PCA) (기출 변형)

PCA공분산행렬고윳값분산설명력수리 연산형
문제
학생 3명의 국어, 수학 시험 성적에 대한 편차 데이터(Centering 완료)가 다음과 같이 행렬 $X$로 주어졌다. $$X=\begin{pmatrix}1&-1\\-2&2\\1&-1\end{pmatrix}$$ (행은 학생 1, 2, 3이며, 1열은 국어 편차, 2열은 수학 편차임)

소문항 1) 위 데이터를 바탕으로 표본 공분산 행렬(Covariance Matrix) $\Sigma$를 구하는 과정을 서술하시오. (단, 표본 공분산이므로 분모는 $n-1$을 적용함)

소문항 2) 공분산 행렬의 고윳값(Eigenvalue)을 구하고, 첫 번째 주성분(PC1)이 전체 분산의 몇 %를 설명하는지(분산 설명력) 계산하시오.

단계별 해설 — 소문항 1

1표본 공분산 행렬 공식

$X$의 각 열이 이미 평균 0인 편차 데이터(centering 완료)이므로, 표본 공분산 행렬은 전치행렬과의 곱으로 바로 구할 수 있다.

$$\Sigma = \frac{1}{n-1}X^\top X \qquad (n=3 \Rightarrow n-1=2)$$
2$X^\top X$ 계산
$$X^\top = \begin{pmatrix}1&-2&1\\-1&2&-1\end{pmatrix}$$ $$X^\top X = \begin{pmatrix}1&-2&1\\-1&2&-1\end{pmatrix}\begin{pmatrix}1&-1\\-2&2\\1&-1\end{pmatrix}$$

각 원소를 계산하면:

$$(1,1): 1{\times}1+(-2){\times}(-2)+1{\times}1 = 1+4+1=6$$ $$(1,2): 1{\times}(-1)+(-2){\times}2+1{\times}(-1) = -1-4-1=-6$$ $$(2,1): (-1){\times}1+2{\times}(-2)+(-1){\times}1 = -1-4-1=-6$$ $$(2,2): (-1){\times}(-1)+2{\times}2+(-1){\times}(-1) = 1+4+1=6$$ $$X^\top X = \begin{pmatrix}6&-6\\-6&6\end{pmatrix}$$
3최종 공분산 행렬
$$\Sigma = \frac{1}{2}\begin{pmatrix}6&-6\\-6&6\end{pmatrix} = \begin{pmatrix}3&-3\\-3&3\end{pmatrix}$$
소문항 1 정답
$$\Sigma = \begin{pmatrix}3&-3\\-3&3\end{pmatrix}$$

단계별 해설 — 소문항 2

4특성방정식 세우기
$$\det(\Sigma-\lambda I)=0 \;\;\Rightarrow\;\; \begin{vmatrix}3-\lambda&-3\\-3&3-\lambda\end{vmatrix}=0$$
5전개 및 정리
$$(3-\lambda)^2-(-3)(-3)=0 \;\;\Rightarrow\;\; \lambda^2-6\lambda+9-9=0 \;\;\Rightarrow\;\; \lambda^2-6\lambda=0$$ $$\lambda(\lambda-6)=0 \;\;\Rightarrow\;\; \lambda_1=6,\ \lambda_2=0$$
6분산 설명력 계산

전체 분산의 총합은 고윳값들의 합(=공분산행렬의 대각합, trace)과 같다.

$$\text{전체 분산} = \lambda_1+\lambda_2 = 6+0=6$$ $$\text{PC1 분산 설명력} = \frac{\lambda_1}{\lambda_1+\lambda_2} = \frac{6}{6} = 1.0\ (100\%)$$
소문항 2 정답
고윳값은 $\lambda_1=6,\ \lambda_2=0$이며, 제1주성분(PC1)이 전체 분산의 100%를 설명한다.
검산 — trace/det 이중 확인: 고유값의 합 $6+0=6=3+3=\text{tr}(\Sigma)$ ✓, 고유값의 곱 $6\times0=0=3\times3-(-3)\times(-3)=9-9=\det(\Sigma)$ ✓. 두 검산 모두 정확히 일치한다.
$\lambda_2=0$이 의미하는 것 — 원본 데이터를 보면 수학 편차는 항상 국어 편차의 정확히 $-1$배다(1열이 $[1,-2,1]$이면 2열은 $[-1,2,-1]$). 즉 두 변수가 완벽한 선형관계(완전한 음의 상관)를 가지므로, 데이터는 사실상 1차원 직선 위에만 분포한다. 이 때문에 두 번째 주성분 방향의 분산이 정확히 0이 되어 $\lambda_2=0$이 나오고, 모든 정보(분산)가 첫 번째 주성분(PC1) 하나에 100% 집중된다 — "$n$개 변수 중 하나가 나머지의 선형결합으로 완전히 설명되면, 공분산행렬의 rank가 그만큼 줄어들고 그에 대응하는 고유값이 정확히 0이 된다"는 PCA의 일반적 성질을 보여주는 좋은 예제다.

37회 다층 퍼셉트론(MLP) 순전파 계산

MLP순전파ReLU·Sigmoid수리 연산형
문제
입력값 $x_1=1,\ x_2=2$이고, 가중치 $w_1=0.5,\ w_2=-0.5$, 편향 $b=1$인 하나의 뉴런이 존재한다.

소문항 1) 활성화 함수 전 단계의 넷 입력값(Net Input, $z$)을 계산하시오.

소문항 2) 활성화 함수로 ReLU를 사용할 때와 시그모이드(Sigmoid)를 사용할 때의 최종 뉴런 출력값을 각각 구하시오.

단계별 해설

1넷 입력값(Net Input) 공식
$$z = (x_1\cdot w_1)+(x_2\cdot w_2)+b$$
2소문항 1 — 숫자 대입
$$z = (1\times0.5)+(2\times{-0.5})+1 = 0.5-1.0+1 = \mathbf{0.5}$$
3소문항 2-1 — ReLU 활성화
$$\text{ReLU}(z)=\max(0,z) = \max(0,0.5) = \mathbf{0.5}$$
4소문항 2-2 — Sigmoid 활성화
$$\sigma(z) = \frac{1}{1+e^{-z}} = \frac{1}{1+e^{-0.5}} = \frac{1}{1+0.6065} = \frac{1}{1.6065} \approx \mathbf{0.622}$$
정답 요약
소문항 1: $z=0.5$  |  소문항 2: ReLU 출력 $=0.5$, Sigmoid 출력 $\approx0.622$
비교 포인트 — $z=0.5>0$이라 ReLU는 입력값을 그대로 통과시켜 $0.5$가 나오지만, Sigmoid는 항상 $(0,1)$ 사이로 압축하므로 $0.5$보다 큰 $0.622$가 나온다(정확히 $z=0$일 때 Sigmoid는 $0.5$). "ReLU는 계산이 단순하고 기울기 소실에 강하지만 Sigmoid는 출력을 확률처럼 해석하기 좋다"는 각 함수의 용도 차이까지 서술하면 가점 요인이 된다.

✅ 학습 체크리스트

  • 지니 불순도 $I_G=1-\sum p_i^2$와 정보 이득(분할 전-분할 후 가중평균)을 직접 계산할 수 있다 (28회)
  • 서포트 벡터·마진의 정의와 하드/소프트 마진의 오차 허용 차이를 슬랙 변수 개념까지 포함해 설명할 수 있다 (29회)
  • 베이즈 정리 공식에 사전확률·가능도를 대입해 사후확률을 계산하고, 라플라스 스무딩의 필요성을 설명할 수 있다 (30회)
  • 배깅(병렬·분산감소)과 부스팅(순차·편향감소)의 샘플링·학습 방식 차이를 구분해 설명할 수 있다 (31회)
  • 오즈·로짓 변환 공식과 BCE 손실함수 수식을 쓰고, 이것이 MLE와 동치임을 설명할 수 있다 (32회)
  • DBSCAN의 Eps·MinPts로 핵심 포인트를 판정하는 기준과, 실루엣 계수 $s=(b-a)/\max(a,b)$의 해석 기준을 설명할 수 있다 (33회)
  • 임계값 상승이 Precision↑·Recall↓로 이어지는 이유와, 임계값에 무관한 지표(ROC/AUC)를 구분해 설명할 수 있다 (34회)
  • 1D 합성곱을 슬라이딩하며 직접 계산할 수 있고, 클래스 불균형 대응 기법(SMOTE·언더샘플링)을 원리와 함께 제시할 수 있다 (35회)
  • 공분산행렬 $\Sigma=\frac{1}{n-1}X^\top X$를 데이터 행렬로부터 직접 계산하고, 특성방정식으로 고윳값을 구해 PC1 분산설명력($\lambda_1/\sum\lambda_i$)까지 산출할 수 있다 (36회)
  • MLP 뉴런의 넷 입력값 $z=\sum w_ix_i+b$ 계산과, ReLU·Sigmoid 활성화 함수의 출력 차이를 설명할 수 있다 (37회)

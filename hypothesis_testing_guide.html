가설검정(Hypothesis Testing) 완전정복

빅데이터분석 · 통계분석 · 머신러닝에서 검정(Test)이 어떻게 하나로 연결되는가

원리 → 이론 → 수식 → 손계산 → 실전 문제까지, 검정의 전체 지도를 그린다.

0검정의 큰 그림 — 세 분야는 왜 만나는가

통계분석은 "표본으로 모집단을 추론"하는 학문이고, 가설검정은 그 추론에 객관적 기준(유의수준)을 부여하는 도구다. 빅데이터분석은 대용량 데이터에서 패턴·차이·관계를 찾아내는데, 그 패턴이 우연인지 실제인지를 판별할 때 검정이 필요하다. 머신러닝은 예측 모델을 만들지만, "이 모델이 저 모델보다 정말 좋은가?", "이 변수가 정말 유의한가?"를 판단할 때 결국 통계적 검정으로 되돌아온다.

즉 세 분야는 "데이터 → 추정 → 검정 → 의사결정"이라는 동일한 파이프라인을 공유한다.

1가설검정의 원리 — 왜, 어떻게 검정하는가

1.1 왜 검정을 하는가

표본에서 관찰된 차이는 ① 모집단에 실제로 존재하는 차이이거나 ② 표본 추출 과정에서 우연히 생긴 오차, 둘 중 하나다. 사람의 직관은 우연과 실제 효과를 구분하지 못한다. 가설검정은 "우연이라면 이런 극단적인 결과가 나올 확률이 얼마나 되는가"를 수치(p-value)로 계산하여, 그 확률이 충분히 작을 때만 "실제 차이"라고 판단하는 객관적 절차다.

1.2 핵심 용어와 논리 구조

귀무가설 H0 / 대립가설 H1

H0(귀무가설): "차이가 없다", "효과가 없다"는 기본 전제. 검정은 항상 H0을 기각할지 말지를 결정하는 구조다.
H1(대립가설): 연구자가 입증하고 싶은 주장. H0이 기각되면 H1을 채택(정확히는 "H0을 기각하지 못할 근거 없음"이 아니라 "채택")한다.

예: H0: μ = 100 (신약 효과 없음) vs H1: μ ≠ 100 (효과 있음)

유의수준 α / 검정통계량 / p-value

α: H0이 참인데도 기각할 위험을 허용하는 한계(보통 0.05). 검정통계량: 표본 데이터를 하나의 숫자(Z, t, F, χ² 등)로 요약한 값. p-value: H0이 참이라는 가정 하에, 관측된 검정통계량만큼 극단적인 값이 나올 확률.

판정 규칙: p-value < α → H0 기각(유의함) / p-value ≥ α → H0 기각 못함(유의하지 않음)

1.3 1종 오류·2종 오류·검정력

H0이 실제로 참H0이 실제로 거짓
H0 기각 못함✅ 옳은 결정 (1-α, 신뢰수준)❌ 2종 오류 β (거짓음성)
H0 기각함❌ 1종 오류 α (거짓양성)✅ 옳은 결정 (1-β, 검정력 Power)
1종 오류(α)는 "없는 효과를 있다고 착각"(재판에서 무죄인 사람을 유죄로), 2종 오류(β)는 "있는 효과를 놓침"(유죄인 사람을 무죄로)이다. 둘은 trade-off 관계이며, α를 낮추면 β가 커지는 경향이 있어 표본크기를 늘려 둘 다 줄이는 것이 이상적이다.

1.4 검정의 표준 절차 (6단계)

1.5 양측검정 vs 단측검정

\[ \text{양측검정: } H_1: \mu \neq \mu_0 \qquad \text{단측검정: } H_1: \mu > \mu_0 \ \text{또는}\ \mu < \mu_0 \]

양측검정은 기각역이 양쪽 꼬리에 α/2씩 나뉘고, 단측검정은 한쪽 꼬리에 α 전체가 몰린다. 방향성이 명확한 연구(예: "새 공법이 기존보다 빠르다")는 단측, 방향을 모르는 경우("차이가 있는가")는 양측을 사용한다.

Q1. 신약이 혈압을 낮춘다는 가설을 검정했더니 p-value = 0.03이 나왔다. α = 0.05일 때 옳은 해석은?
Q2. 실제로는 두 그룹 간 차이가 없는데(H0 참), 검정 결과 "차이가 있다"고 잘못 판단했다. 이것은?

2검정의 분류 체계

2.1 모수적 검정 vs 비모수적 검정

모수(Parametric) 모집단이 특정 분포(주로 정규분포)를 따른다고 가정하고, 평균·분산 같은 모수를 직접 검정. 데이터가 크고 정규성을 만족할 때 강력함.
비모수(Non-parametric) 분포 가정이 없거나 약함. 순위(rank) 기반으로 검정. 표본이 작거나 정규성이 깨질 때 사용.

2.2 전체 검정 분류 지도

데이터가 정규성을 만족하는지 먼저 확인(점선 경로) → 만족하면 모수적, 아니면 비모수적 검정을 선택하는 것이 실무 표준 흐름

3Z검정 — 모분산을 아는 경우의 평균·비율 검정

3.1 원리

모집단의 분산 σ²을 알고 있거나 표본크기가 충분히 커서(n≥30) 표본평균이 중심극한정리에 의해 정규분포에 근사할 때 사용한다. 표본평균을 표준정규분포로 변환하여 검정한다.

\[ Z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}} \sim N(0,1) \qquad\qquad Z_{\hat p} = \frac{\hat p - p_0}{\sqrt{p_0(1-p_0)/n}} \]

3.2 손계산 예제

[문제] 모집단 표준편차 σ=15로 알려진 시험점수. 표본 n=36, 표본평균 x̄=82. H0: μ=78 vs H1: μ≠78, α=.05 [Step1] 표준오차 SE = σ/√n = 15/√36 = 15/6 = 2.5 [Step2] Z = (82-78)/2.5 = 4/2.5 = 1.6 [Step3] 임계값 Z(0.025) = ±1.96 → |1.6| < 1.96 [결론] H0 기각 못함 → 평균이 78과 유의하게 다르다고 할 수 없음
Q. 어느 공장 부품의 모표준편차가 4로 알려져 있다. n=64, x̄=51, H0: μ=50. Z값은?

4t검정 — 모분산을 모를 때의 평균 비교

4.1 원리 및 3가지 유형

모분산 σ²을 모르고 표본크기가 작을 때(n<30), 표본표준편차 s로 σ를 대체하면 정규분포보다 꼬리가 두꺼운 t분포(자유도 df에 의존)를 따른다.

유형상황자유도
단일표본 t검정표본평균 vs 특정 기준값 비교n-1
독립표본 t검정서로 다른 두 그룹 평균 비교(예: 남/여)n1+n2-2
대응표본 t검정같은 대상의 사전-사후 비교n-1 (차이값 기준)
\[ \text{단일표본: } t = \frac{\bar{x}-\mu_0}{s/\sqrt n} \qquad \text{독립표본: } t=\frac{\bar x_1 - \bar x_2}{\sqrt{s_p^2(\frac1{n_1}+\frac1{n_2})}},\ \ s_p^2=\frac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2-2} \] \[ \text{대응표본: } t = \frac{\bar d}{s_d/\sqrt n} \]

4.2 손계산 예제 — 독립표본 t검정

[문제] A반(n1=10) 평균 78, 분산 16 / B반(n2=12) 평균 74, 분산 20. H0: μA=μB [Step1] 합동분산 sp² = [(10-1)*16 + (12-1)*20] / (10+12-2) = (144+220)/20 = 18.2 [Step2] SE = √(18.2*(1/10+1/12)) = √(18.2*0.1833) = √3.337 = 1.827 [Step3] t = (78-74)/1.827 = 2.19, df=20 [Step4] t(0.025, df=20) ≈ 2.086 → |2.19| > 2.086 [결론] H0 기각 → 두 반의 평균은 유의하게 다르다 (α=.05)
Q. 다이어트 프로그램 전후 체중 차이(대응표본)를 검정할 때 자유도(df)는 표본수 n=15일 때?

5F검정 — 분산의 비율을 이용하는 검정들

5.1 원리

F검정은 "두 집단 분산 비교" 하나만을 가리키는 이름이 아니라, 두 분산(또는 두 변동)의 비율이 F분포를 따르는 모든 검정을 통칭한다. 즉 "분산비 = 1인가?"라는 동일한 논리가 여러 국면에 반복해서 등장한다.

\[ F = \frac{s_1^2}{s_2^2} \sim F_{(n_1-1,\ n_2-1)} \quad (\text{관례상 } s_1^2 \ge s_2^2 \text{ 로 두어 } F\ge1) \]

5.2 손계산 예제

[문제] 그룹1(n1=13) 분산 s1²=25, 그룹2(n2=10) 분산 s2²=9. 등분산인가? [Step1] F = 25/9 = 2.78, df1=12, df2=9 [Step2] F(0.025, 12, 9) ≈ 3.87 (양측검정이므로 α/2 임계값 사용) [Step3] 2.78 < 3.87 이므로 기각역 밖 [결론] H0 기각 못함 → 등분산 가정 유지, 이후 t검정에서 합동분산 사용 가능
실무 팁: 등분산 여부에 따라 t검정의 자유도 계산법이 달라진다(등분산이면 n1+n2-2, 이분산이면 Welch's t-test로 자유도를 근사 계산).
Q. F검정 통계량은 항상 어떤 값을 가지는가?

5.3 F검정의 다양한 활용 — 등분산 비교만이 아니다

F검정은 크게 네 가지 국면에서 쓰인다. 5.1~5.2는 그중 ①번(등분산 비교)이고, ②③은 각각 7장(ANOVA)·8장(회귀)에서 이미 다뤘다. 여기서는 아직 다루지 않은 ④ 중첩모형 비교(Partial F-test)를 새로 추가한다.

유형비교 대상다루는 장
① 등분산검정두 집단의 분산 s1² vs s2²5.1~5.2 (본 절)
② ANOVA F검정집단간 변동 MSB vs 집단내 변동 MSW7장
③ 회귀모형 전체 유의성회귀로 설명된 변동 MSR vs 잔차 MSE8장
④ 중첩모형 비교 (Partial F-test)변수를 추가하기 전/후 모형의 잔차제곱합(SSE) 감소량본 절 5.4 (신규)

5.4 중첩모형 비교 F검정 (Partial F-test)

회귀모형에 변수를 새로 추가했을 때, 그 변수(들)가 모형 설명력을 유의하게 개선하는지를 검정한다. "축소모형(Reduced)"과 "완전모형(Full)"의 잔차제곱합(SSE) 차이를 이용하며, 변수선택(Stepwise)의 이론적 근거가 된다.

\[ F = \frac{(SSE_R - SSE_F)/(k_F-k_R)}{SSE_F/(n-k_F-1)} \sim F_{(k_F-k_R,\ n-k_F-1)} \]

R: 축소모형(변수 적음), F: 완전모형(변수 많음), k: 각 모형의 독립변수 개수

[문제] n=30. 축소모형(변수 2개) SSE_R=150. 완전모형(변수 4개, 2개 추가) SSE_F=110 [Step1] 분자 자유도 = k_F - k_R = 4-2 = 2, 분모 자유도 = n-k_F-1 = 30-4-1 = 25 [Step2] F = [(150-110)/2] / [110/25] = (40/2) / (4.4) = 20 / 4.4 = 4.55 [Step3] F(0.05, 2, 25) ≈ 3.39 → 4.55 > 3.39 [결론] H0(추가 변수들의 계수=0) 기각 → 새로 추가한 2개 변수는 모형 설명력을 유의하게 개선함
변수 1개만 추가하는 경우 Partial F-test는 그 변수의 t검정과 동일한 결론을 준다(F=t²). 여러 변수를 한꺼번에 추가/제거할 때는 t검정으로 한 번에 판단할 수 없으므로 Partial F-test가 필요하다.
Q. 완전모형에 변수를 5개→8개로 늘렸다(3개 추가), n=50, SSE_R=200, SSE_F=140. F통계량의 분자 자유도와 분모 자유도는?

6카이제곱검정 — 범주형 자료의 검정

6.1 세 가지 용도

종류목적
적합도검정 (Goodness of Fit)한 범주형 변수가 특정 분포(비율)를 따르는지
독립성검정 (Independence)두 범주형 변수가 서로 독립인지 (교차표)
동질성검정 (Homogeneity)여러 모집단에서 범주 비율이 동일한지
\[ \chi^2 = \sum \frac{(O_i - E_i)^2}{E_i} \sim \chi^2_{(df)} \] \[ \text{독립성검정 } df=(r-1)(c-1),\quad E_{ij}=\frac{\text{행합}\times\text{열합}}{\text{전체합}} \]

6.2 손계산 예제 — 독립성검정

[문제] 성별×제품선호 교차표. 남 (선호40,비선호10=50) / 여 (선호30,비선호20=50), 전체100 [Step1] 기대빈도 E(남,선호)=50*70/100=35, E(남,비선호)=50*30/100=15 E(여,선호)=50*70/100=35, E(여,비선호)=50*30/100=15 [Step2] χ² = (40-35)²/35 + (10-15)²/15 + (30-35)²/35 + (20-15)²/15 = 25/35 + 25/15 + 25/35 + 25/15 = 0.714+1.667+0.714+1.667 = 4.76 [Step3] df=(2-1)(2-1)=1, χ²(0.05,1)=3.841 [결론] 4.76 > 3.841 → H0 기각, 성별과 제품선호는 유의한 관련이 있음

6.3 범주형이 아닐 때 — 카이제곱을 연속형 데이터에 쓰는 경우

카이제곱검정은 "빈도(도수)"를 다루는 검정이라 범주형 자료의 전유물처럼 보이지만, χ² 분포 자체는 연속형 확률변수다. 정규분포를 따르는 연속형 데이터에서도 다음 두 상황에서 카이제곱검정을 사용한다.

용도데이터 성격H0
① 모분산 검정 (단일표본)연속형 (정규분포 가정)σ² = σ0² (분산이 특정 값과 같다)
② 적합도검정을 연속형에 적용 (구간화)연속형 → 구간(계급)으로 나눠 도수화특정 분포(정규분포 등)를 따른다

6.3.1 모분산 검정 — 연속형 데이터의 분산이 특정 값과 같은가

표본분산 s²이 모분산 σ0²과 같은지 검정할 때, 정규모집단이라면 다음 통계량이 자유도 n-1인 카이제곱분포를 따른다. 이때 데이터는 개별 연속형 측정값(예: 부품의 길이, 시험 점수)이지 빈도가 아니다.

\[ \chi^2 = \frac{(n-1)s^2}{\sigma_0^2} \sim \chi^2_{(n-1)} \]
[문제] 부품 길이(mm, 연속형) 표본 n=15, 표본분산 s²=6.4. "모분산이 4.0이다"(σ0²=4)라는 주장을 α=.05로 검정 (양측) [Step1] χ² = (n-1)*s² / σ0² = 14*6.4 / 4 = 89.6/4 = 22.4 [Step2] df=14, 양측이므로 하한 χ²(0.975,14)=5.629, 상한 χ²(0.025,14)=26.119 [Step3] 5.629 < 22.4 < 26.119 → 기각역 밖 [결론] H0 기각 못함 → 모분산이 4.0이 아니라고 할 근거 없음
모분산 검정의 χ² 분포는 좌우 비대칭이라서, 등분산 F검정(두 집단 비교)과 달리 상한과 하한 임계값을 따로 구해 양쪽에서 판정해야 한다(위 예시처럼 α/2씩 나눠 양쪽 검정).

6.3.2 적합도검정을 연속형 분포 확인에 쓰는 경우

연속형 데이터라도 구간을 나눠 도수표로 변환하면 "이 데이터가 정규분포(혹은 다른 이론분포)를 따르는가"를 카이제곱 적합도검정으로 확인할 수 있다. 다만 표본이 크지 않다면 정규성 확인은 Shapiro-Wilk나 K-S검정이 더 일반적으로 쓰인다(9장 참고).

\[ \chi^2 = \sum_{i=1}^{k} \frac{(O_i-E_i)^2}{E_i},\quad E_i = n \times P(\text{구간 } i \text{에 속할 이론 확률}) \]

7분산분석 ANOVA — 3개 이상 집단 평균 비교

7.1 원리

t검정을 여러 번 반복하면 1종 오류가 누적되는 문제(다중비교 문제)가 생긴다. ANOVA는 전체 변동을 집단간 변동(SSB)과 집단내 변동(SSW)으로 분해하여 한 번에 검정한다. "평균의 차이"를 "분산의 비율(F)"로 검정하는 것이 핵심 아이디어다.

\[ SST = SSB + SSW \qquad F = \frac{MSB}{MSW} = \frac{SSB/(k-1)}{SSW/(N-k)} \sim F_{(k-1,\,N-k)} \]

7.2 손계산 예제 — 일원배치 ANOVA

[문제] 3개 비료(A,B,C) 각 3개 표본 수확량: A(4,5,6) B(7,8,9) C(10,11,12) [Step1] 각 그룹평균: Ā=5, B̄=8, C̄=11, 전체평균 Ḡ=8 [Step2] SSB = 3*(5-8)²+3*(8-8)²+3*(11-8)² = 3*9+0+3*9 = 54 [Step3] SSW = 그룹내 편차제곱합 = (1+0+1)+(1+0+1)+(1+0+1) = 2+2+2 = 6 [Step4] df between=k-1=2, df within=N-k=9-3=6 MSB=54/2=27, MSW=6/6=1 [Step5] F = 27/1 = 27, F(0.05,2,6)=5.14 [결론] 27 > 5.14 → H0 기각, 비료 종류에 따라 수확량 평균이 유의하게 다름
ANOVA에서 H0 기각 후 어느 그룹끼리 다른지 알려면 Tukey HSD, Bonferroni 등의 사후검정(post-hoc test)이 추가로 필요하다.

8상관계수·회귀계수 검정

8.1 상관계수 검정

피어슨 상관계수 r이 모집단에서 0인지(선형관계 없음) 검정한다.

\[ t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}} \sim t_{(n-2)} \]

8.2 회귀계수 검정

단순/다중회귀에서 각 회귀계수 β가 0인지 검정(=해당 변수가 종속변수에 유의한 영향을 주는지), 모형 전체의 유의성은 F검정으로 판단한다.

\[ t = \frac{\hat\beta_1}{SE(\hat\beta_1)} \sim t_{(n-2)} \qquad F = \frac{MSR}{MSE} = \frac{SSR/k}{SSE/(n-k-1)} \]

8.3 손계산 예제 — 상관계수 검정

[문제] n=20, 표본상관계수 r=0.5. H0: ρ=0 [Step1] t = 0.5*√(20-2) / √(1-0.25) = 0.5*√18 / √0.75 [Step2] = 0.5*4.243 / 0.866 = 2.121 / 0.866 = 2.45 [Step3] t(0.025, df=18) = 2.101 → 2.45 > 2.101 [결론] H0 기각 → 상관관계가 통계적으로 유의함

9정규성 검정 — 모수적 검정의 전제조건 확인

9.1 왜 필요한가

t검정, ANOVA, 피어슨 상관 등 모수적 검정은 데이터가 정규분포를 따른다고 가정한다. 이 가정이 깨지면 비모수 검정으로 전환해야 한다.

방법특징
Shapiro-Wilk 검정표본크기 < 2000에 적합, 소표본에서 검정력 우수, 가장 널리 사용
Kolmogorov-Smirnov 검정표본분포와 이론분포의 최대 누적확률 차이(D) 이용, 대표본에 적합
Q-Q Plot시각적 진단 도구, 점들이 45도 직선에서 벗어나면 비정규성 의심
\[ H_0: \text{데이터는 정규분포를 따른다} \qquad H_1: \text{정규분포를 따르지 않는다} \]
정규성 검정은 다른 검정과 반대로 p ≥ α이면 "정규성을 만족한다(H0 기각 못함)"는 결론을 내리는 구조라 해석에 주의해야 한다.

10.1 손계산 예제 — Mann-Whitney U

11머신러닝에서의 검정 활용

11.1 모델 성능 비교: McNemar 검정

같은 테스트셋에 대해 두 분류모델의 정오답 여부가 대응(paired)되므로, 독립표본이 아닌 McNemar 검정을 사용한다. 두 모델이 서로 다르게 틀린 경우(불일치 셀)만 비교한다.

\[ \chi^2 = \frac{(|b-c|-1)^2}{b+c} \sim \chi^2_{(1)} \]

b: 모델A만 맞고 B는 틀림 / c: 모델B만 맞고 A는 틀림 (연속성 수정 포함)

11.2 교차검증 결과 비교: 대응표본 t검정

K-fold 교차검증에서 각 fold의 정확도를 모델A, 모델B 쌍으로 얻으면, fold별 차이값에 대응표본 t검정을 적용해 두 모델의 평균 성능 차이가 유의한지 검정한다.

CNN 기초 완전정복

합성곱 신경망의 핵심 개념 — 특히 헷갈리기 쉬운 Kernel(커널)과 Channel(채널)의 차이를 명확히 구분합니다

원문: Aayushmaan Jain, "Basics of Convolutional Neural Networks using Pytorch Lightning" (Medium, 2023) 내용을 재구성·확장한 학습서

Convolution Kernel vs Channel Pooling Loss & Training Tricks

1CNN이 필요한 이유

일반적인 인공신경망(ANN, 예: MLP)은 이미지처럼 공간 정보(spatial information)를 가진 데이터를 처리하도록 설계되지 않았습니다. 이미지를 MLP에 넣으려면 2차원 픽셀 배열을 1차원으로 펼쳐야(flatten) 하는데, 이 과정에서 픽셀들이 원래 가지고 있던 공간적 배치 정보(어떤 픽셀이 어떤 픽셀과 인접해 있었는지)가 사라집니다.

반면 CNN은 무작위로 초기화된 커널(kernel)을 이미지에 합성곱(convolution)시키는 방식으로 동작하며, 이 커널의 값들은 역전파 과정에서 점차 갱신됩니다.

1-1. 등변성(Equivariance)과 이동 불변성

CNN은 등변성(equivariant)을 가진다는 중요한 성질이 있습니다. 즉, "먼저 이미지를 변형(augment)한 뒤 합성곱을 수행한 결과"와 "먼저 합성곱을 수행한 뒤 이미지를 변형한 결과"로 얻어지는 특징 맵(feature map)이 동일합니다. 이 성질 덕분에 CNN은 이미지의 공간적 변형에 대해 강건한(invariant) 특성을 갖게 됩니다.

2CNN의 3단 구조

CNN은 크게 세 가지 구성요소로 이루어집니다.

구성요소역할
① 특징 추출기 (Feature Extractor)이미지에 합성곱을 수행해 공간 정보를 추출. 여러 개의 합성곱 블록(Convolution Block)으로 구성됨
② 평탄화 (Flattening)다차원 특징 맵을 분류 헤드가 처리할 수 있는 1차원 벡터로 변환
③ 분류 헤드 (Classification Head)여러 개의 완전연결층(fully connected layer)으로 구성되어 최종 분류(또는 회귀)를 수행

①의 특징 추출기는 다시 합성곱 층(Convolution layer) → 활성화 함수(Activation) → 풀링 층(Pooling) 세 요소로 구성된 블록을 반복하는 구조입니다.

3합성곱 층 핵심 용어

합성곱 연산을 이해하려면 다음 다섯 가지 용어를 먼저 정리해야 합니다.

용어정의
Kernel (커널)이미지에 합성곱을 수행하는 필터. 학습 가능한 가중치 값들로 구성됨
Stride (스트라이드)합성곱을 수행하면서 커널이 한 번에 이동하는 픽셀 수
Padding (패딩)합성곱 시 이미지 가장자리에 추가하는 픽셀 수. 합성곱은 본래 이미지 크기를 줄이므로, 크기를 보존하기 위해 주로 사용
Kernel size (커널 크기)합성곱에 사용되는 커널의 크기(예: 3×3, 5×5). 큰 커널일수록 학습은 빨라지지만 세부 정보(디테일)를 잃기 쉬움
Number of filters (필터 개수)이미지에 적용되는 합성곱 필터의 개수. 각 필터는 채널 방향으로 쌓여(stacked) 출력의 채널 수를 결정함
주목 — 표의 마지막 줄("필터 개수는 채널 방향으로 쌓인다")이 바로 다음 장에서 다룰 Kernel과 Channel의 관계의 핵심입니다.

4Kernel vs Channel 완전정리 ★

CNN을 처음 배울 때 가장 자주 혼동하는 지점이 바로 커널(Kernel)과 채널(Channel)입니다. 이름도 비슷하고 둘 다 합성곱과 관련이 있지만, 실제로는 전혀 다른 층위의 개념입니다.

4-1. 한 줄 정의

Kernel (커널)Channel (채널)
무엇인가합성곱 연산에 사용되는 학습 가능한 필터(가중치 묶음) — "도구"입력/출력 텐서가 가진 깊이(depth) 방향의 한 층(슬라이스) — "데이터의 구조"
비유이미지를 훑으며 특정 패턴(에지, 색상 대비 등)을 찾아내는 "탐지기"하나의 탐지기가 만들어낸 결과가 쌓이는 "서랍 한 칸"
예시3×3 커널, 5×5 커널RGB 이미지 = 3채널, 어떤 층의 특징맵 64장 = 64채널
개수를 정하는 주체설계자가 "필터를 몇 개 쓸지" 직접 정함(하이퍼파라미터)입력 채널 수는 데이터가 결정, 출력 채널 수는 커널(필터) 개수가 결정

4-2. 커널의 "숨은 깊이" — 왜 헷갈리는가

가장 중요한 포인트는 이것입니다: 커널 하나는 사실 2차원이 아니라, 입력 채널 수만큼의 깊이를 가진 3차원 구조라는 점입니다.

예를 들어 RGB 이미지(3채널)에 3×3 커널을 적용한다면, 그 커널의 실제 모양은 $3\times3\times3$(가로×세로×입력채널)입니다. 이 하나의 커널(=하나의 필터)이 R, G, B 세 채널의 정보를 동시에 훑으며 계산한 뒤, 그 결과를 모두 합산해서 단 하나의 2차원 출력(=출력 채널 1장)을 만듭니다.

따라서 "출력 채널을 몇 장 만들고 싶은가"는 곧 "커널(필터)을 몇 개 사용할 것인가"와 같은 질문이 됩니다. 필터를 $N$개 사용하면, 각 필터가 독립적으로 하나씩의 출력 채널을 만들어내므로 최종 출력은 $N$개의 채널을 가진 특징 맵 묶음이 됩니다.

4-3. 정리하면

  • 채널(Channel)은 "데이터가 몇 겹으로 쌓여 있는가"를 나타내는 개념 — 입력의 채널 수(예: RGB=3), 또는 어떤 층을 통과한 뒤의 특징맵 개수를 가리킵니다.
  • 커널(Kernel, 필터)은 "그 데이터를 훑으며 패턴을 찾아내는 학습 가능한 도구"입니다.
  • 커널 하나의 깊이는 항상 입력 채널 수와 자동으로 일치하며, 사용자가 별도로 설정하지 않습니다. 사용자가 직접 설정하는 것은 커널의 가로×세로 크기(kernel size)와 개수(number of filters)입니다.
  • 커널을 몇 개 사용하느냐가 곧 다음 층의 채널 수(출력 채널 수)를 결정합니다.
한 문장 요약 — "채널은 데이터의 층(layer)이고, 커널은 그 층들을 동시에 읽어 새로운 층 하나를 만들어내는 필터다."

5활성화 함수

활성화 함수는 특징 맵에 비선형성(nonlinearity)을 도입하는 함수입니다. 비선형성이 없다면, 여러 번의 합성곱을 연속으로 수행한 결과는 사실 하나의 (다른) 커널을 사용한 단일 합성곱과 수학적으로 동일해집니다. 즉 층을 아무리 깊게 쌓아도 표현력이 늘어나지 않습니다. 비선형성을 도입함으로써 CNN은 훨씬 더 복잡한 패턴을 학습할 수 있게 됩니다.

6풀링 (Pooling)

합성곱을 반복할수록 파라미터 수가 늘어나 학습 시간이 길어지는 문제가 있습니다. 풀링(Pooling) 기법은 이미지가 가진 핵심 정보는 최대한 보존하면서 파라미터 수를 크게 줄이는 역할을 합니다.

풀링은 보통 2×2 크기의 윈도우를 특징 맵 위에서 슬라이딩하며, 각 윈도우에서 대표값 하나를 뽑아내는 방식으로 이루어집니다.

종류방식
Max Pooling윈도우 내에서 가장 큰 값을 선택
Min Pooling윈도우 내에서 가장 작은 값을 선택
Average Pooling윈도우 내 모든 값의 평균을 계산

7출력 크기 공식과 손계산

합성곱을 거친 뒤 특징 맵의 크기는 다음 공식으로 계산합니다.

$$ \text{출력 크기} = \left\lfloor \frac{n + 2p - k}{s} \right\rfloor + 1 $$

여기서 $n$은 입력 이미지의 한 변 크기, $p$는 패딩, $k$는 커널 크기, $s$는 스트라이드입니다.

  • $2p$인 이유 — 패딩은 이미지의 양쪽(위/아래 또는 좌/우) 모두에 추가되기 때문입니다.
  • $-k$인 이유 — 커널이 이미지 전체를 훑으려면 $(n-k)$번의 이동이 필요하기 때문입니다.
  • $\div s$인 이유 — 스트라이드는 커널이 한 번의 합성곱 연산 후 몇 칸씩 이동하는지를 나타내기 때문입니다.

풀링을 거친 뒤 크기 역시 유사하게, 입력 크기를 풀링 윈도우 크기로 나눈 뒤 내림(floor division)하여 계산합니다.

7-1. 손계산 예제

$7\times7$ 입력 이미지에 $3\times3$ 커널, 패딩 $p=1$, 스트라이드 $s=2$를 적용한다고 하면:

$$ \left\lfloor \frac{7 + 2(1) - 3}{2} \right\rfloor + 1 = \left\lfloor \frac{6}{2} \right\rfloor + 1 = 3 + 1 = 4 $$

즉 출력 특징 맵의 크기는 $4\times4$가 됩니다 (채널 수는 별도로 사용한 필터 개수만큼 결정됩니다 — 4장 참고).

8손실 함수

CNN은 이미지 분류(classification)뿐 아니라 이미지 회귀(regression) 문제에도 사용되며, 과제 유형에 따라 다른 손실 함수를 사용합니다.

과제 유형대표 손실 함수
이미지 회귀 (Image Regression)MSE, MAE, Huber Loss
이미지 분류 (Image Classification)Hinge Loss, Cross Entropy Loss

9학습 가속 기법

기법효과
배치 정규화 (Batch Normalization) ① 학습 속도 향상 ② 더 큰 학습률(learning rate) 사용 가능 ③ 가중치 초기화 방식에 덜 민감해짐 — 세 가지 이점을 동시에 제공
Global Average Pooling (GAP) 분류 헤드로 넘기기 전, Flatten 대신 각 채널의 평균값 하나씩을 뽑아 1차원으로 변환. 채널별 정보를 압축적으로 담아내는 동시에 학습해야 할 파라미터 수를 크게 줄여줌

10CNN은 무엇을 학습하는가

CNN은 특징 맵을 추출하는 과정에서 이미지의 공간 정보를 보존합니다. 여러 개의 필터로 합성곱을 반복하면서, CNN은 에지(edge), 형태(shape), 객체(object) 등 다양한 공간적 특징을 계층적으로 학습합니다. 이렇게 얻어진 특징들은 평탄화되어 분류 헤드(클래스 예측) 또는 회귀 헤드(수치 예측)로 전달됩니다.

일반적으로 네트워크의 앞쪽 층은 에지나 색상 대비 같은 단순한 저수준(low-level) 특징을, 뒤쪽 층은 이러한 저수준 특징들이 조합된 형태·객체 같은 고수준(high-level) 특징을 학습하는 경향이 있습니다.

11종합 정리표

개념핵심 요약
Kernel(커널)패턴을 찾아내는 학습 가능한 필터. 깊이는 항상 입력 채널 수와 같음
Channel(채널)데이터의 깊이 방향 층. 입력 채널은 데이터가, 출력 채널은 커널 개수가 결정
Stride커널이 한 번에 이동하는 픽셀 수 — 클수록 출력 크기 감소
Padding가장자리에 추가하는 픽셀 — 출력 크기 보존 목적
Pooling파라미터 수를 줄이며 핵심 정보 보존 (Max/Min/Average)
활성화 함수비선형성 도입 → 복잡한 패턴 학습 가능
Batch Normalization학습 속도·안정성 향상
Global Average PoolingFlatten 대체, 파라미터 절감 + 채널별 정보 압축

12학습 체크리스트

  • MLP가 이미지 처리에서 공간 정보를 잃는 이유(flatten)를 설명할 수 있다
  • CNN의 등변성(equivariance)이 무엇을 의미하는지 설명할 수 있다
  • CNN의 3단 구조(특징추출기/평탄화/분류헤드)를 순서대로 말할 수 있다
  • 커널과 채널의 차이를 한 문장으로 설명할 수 있다
  • 커널 하나의 깊이가 왜 항상 입력 채널 수와 같은지 설명할 수 있다
  • 필터(커널) 개수가 왜 출력 채널 수를 결정하는지 설명할 수 있다
  • Stride, Padding, Kernel size가 출력 크기에 미치는 영향을 각각 설명할 수 있다
  • 출력 크기 공식 $\lfloor(n+2p-k)/s\rfloor+1$을 직접 손으로 계산할 수 있다
  • Max/Min/Average Pooling의 차이를 설명할 수 있다
  • Batch Normalization과 Global Average Pooling이 각각 어떤 이점을 주는지 설명할 수 있다

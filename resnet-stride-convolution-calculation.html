ResNet 합성곱·스트라이드 출력크기 완전정복

He et al. (2015) "Deep Residual Learning for Image Recognition" 논문의 ResNet-50 아키텍처 스펙을 이용해, 224×224 입력이 각 단계에서 어떤 크기로 줄어드는지 손계산으로 직접 추적합니다

1합성곱 출력 크기 공식

합성곱(또는 풀링) 층을 통과한 뒤 특징 맵의 한 변 크기는 다음 공식으로 계산합니다.

$$ O = \left\lfloor \frac{N + 2P - K}{S} \right\rfloor + 1 $$
기호의미
$N$입력 특징 맵의 한 변 크기
$P$패딩(padding) — 이미지 양쪽에 추가되는 픽셀 수이므로 $2P$로 계산
$K$커널(필터) 크기
$S$스트라이드 — 커널이 한 번에 이동하는 픽셀 수
$O$출력 특징 맵의 한 변 크기
핵심 관찰 — 스트라이드 $S$가 분모에 있기 때문에, $S=1$이면 크기 변화가 거의 없고(패딩으로 보존 가능), $S=2$이면 출력 크기가 대략 절반으로 줄어듭니다. ResNet은 이 성질을 이용해 풀링 없이도 순수 합성곱만으로 다운샘플링을 수행하는 구간을 여러 곳에 배치합니다.

3Stage별 손계산 — Conv1 · MaxPool

3-1. Conv1: 7×7, 64채널, stride 2, padding 3

입력: $224\times224\times3$

[계산] O = ⌊(N + 2P − K) / S⌋ + 1 = ⌊(224 + 2×3 − 7) / 2⌋ + 1 = ⌊(224 + 6 − 7) / 2⌋ + 1 = ⌊223 / 2⌋ + 1 = 111 + 1 = 112

→ Conv1 통과 후 크기: $112\times112\times64$ (출력 채널 수 64는 사용한 필터 개수와 같음)

3-2. MaxPool: 3×3, stride 2, padding 1

입력: $112\times112\times64$

[계산] O = ⌊(112 + 2×1 − 3) / 2⌋ + 1 = ⌊(112 + 2 − 3) / 2⌋ + 1 = ⌊111 / 2⌋ + 1 = 55 + 1 = 56

→ MaxPool 통과 후 크기: $56\times56\times64$

4Stage별 손계산 — Stage 1~4

ResNet의 Bottleneck 블록은 $1\times1 \to 3\times3 \to 1\times1$ 세 개의 합성곱으로 구성됩니다. 이 중 크기를 줄이는 역할은 오직 중간의 $3\times3$ 합성곱이 담당하며, 각 Stage의 첫 번째 블록에서만 stride=2를 적용해 다운샘플링을 수행합니다. 나머지 블록들은 모두 stride=1로 크기를 유지합니다.

4-1. Stage 1 (conv2_x): stride 1 — 크기 유지

입력: $56\times56\times64$, 3×3 conv (K=3, S=1, P=1)

[계산] O = ⌊(56 + 2×1 − 3) / 1⌋ + 1 = ⌊55 / 1⌋ + 1 = 55 + 1 = 56

→ Stage 1 출력: $56\times56\times256$ (stride=1이므로 크기 변화 없음, 채널만 256으로 확장)

4-2. Stage 2 (conv3_x): 첫 블록 stride 2 — 절반으로 축소

입력: $56\times56\times256$, 3×3 conv (K=3, S=2, P=1)

[계산] O = ⌊(56 + 2×1 − 3) / 2⌋ + 1 = ⌊55 / 2⌋ + 1 = 27 + 1 = 28

→ Stage 2 출력: $28\times28\times512$

4-3. Stage 3 (conv4_x): 첫 블록 stride 2

입력: $28\times28\times512$, 3×3 conv (K=3, S=2, P=1)

[계산] O = ⌊(28 + 2×1 − 3) / 2⌋ + 1 = ⌊27 / 2⌋ + 1 = 13 + 1 = 14

→ Stage 3 출력: $14\times14\times1024$

4-4. Stage 4 (conv5_x): 첫 블록 stride 2

입력: $14\times14\times1024$, 3×3 conv (K=3, S=2, P=1)

[계산] O = ⌊(14 + 2×1 − 3) / 2⌋ + 1 = ⌊13 / 2⌋ + 1 = 6 + 1 = 7

→ Stage 4 출력: $7\times7\times2048$

4-5. Global Average Pooling

$7\times7\times2048$ 특징 맵 각 채널을 통째로 평균 내어 $1\times1\times2048$ 벡터로 압축한 뒤, Fully-Connected 층을 거쳐 1000개 클래스에 대한 확률을 출력합니다.

패턴 확인 — Stage 2, 3, 4는 모두 "$3\times3$, K=3, S=2, P=1" 동일한 설정을 사용하며, 계산 결과 각각 정확히 절반씩 줄어드는 것을 확인할 수 있습니다: 56→28→14→7. 이는 $S=2$일 때 $K=3, P=1$ 조합이 "정확히 절반으로 나누기"를 만드는 표준적인 설계 패턴이기 때문입니다.

5Bottleneck 블록과 스트라이드 위치

왜 stride=2를 $1\times1$이 아니라 중간의 $3\times3$ 합성곱에 배치할까요? $1\times1$ 합성곱은 공간 정보를 전혀 훑지 않고 채널 방향의 선형결합만 수행하므로, 여기에 stride를 적용하면 픽셀을 그냥 건너뛰며 버리는 셈이 되어 정보 손실이 커집니다. 반면 $3\times3$ 합성곱은 이웃 픽셀 정보를 실제로 종합하면서 이동하므로, 같은 stride=2라도 더 적은 정보 손실로 다운샘플링할 수 있습니다.

이때 skip connection(shortcut) 경로도 출력 크기·채널 수를 맞춰야 하므로, 각 Stage의 첫 블록에서는 shortcut에도 $1\times1$ 합성곱을 stride=2로 적용해 공간 크기와 채널 수를 본류(main path)와 일치시킵니다 (이를 projection shortcut이라 부릅니다).

6전체 파이프라인 다이어그램

정리하면 224에서 7까지 줄어드는 과정은 총 5번의 stride=2 다운샘플링(Conv1, MaxPool, Stage2·3·4의 첫 블록)으로 이루어지며, $224 / 2^5 = 224/32 = 7$로 정확히 맞아떨어지는 것을 확인할 수 있습니다.

7Receptive Field 누적 계산 (심화)

각 층을 통과할 때마다 출력의 한 픽셀이 "실제로 입력 이미지에서 얼마나 넓은 영역을 보고 있는지"를 수용영역(Receptive Field, RF)이라 합니다. 누적 공식은 다음과 같습니다.

$$ RF_{l} = RF_{l-1} + (K_l - 1)\times \prod_{i=1}^{l-1}S_i $$

Conv1(K=7,S=2)과 MaxPool(K=3,S=2)만 적용한 경우를 손계산해보면:

[Conv1] RF₁ = 1 + (7−1)×1 = 7 [Pool] RF₂ = 7 + (3−1)×2 = 7 + 4 = 11

즉 MaxPool 직후의 특징 맵 픽셀 하나는 이미 원본 이미지에서 $11\times11$ 크기의 영역 정보를 담고 있습니다. Stage를 거듭할수록 이 값은 누적되어, Stage4 끝에서는 수용영역이 입력 이미지 전체를 훨씬 뛰어넘는 크기로 커집니다 — 이는 네트워크 뒷단으로 갈수록 더 넓은 문맥(전역적 패턴)을 반영할 수 있게 되는 이유이기도 합니다.

9학습 체크리스트

  • 합성곱 출력 크기 공식 $\lfloor(N+2P-K)/S\rfloor+1$의 각 기호가 무엇을 뜻하는지 설명할 수 있다
  • ResNet-50의 Conv1(7×7,s=2,p=3)이 224→112를 만드는 과정을 손으로 계산할 수 있다
  • MaxPool(3×3,s=2,p=1)이 112→56을 만드는 과정을 손으로 계산할 수 있다
  • Stage 2·3·4에서 왜 항상 첫 번째 블록에서만 stride=2를 쓰는지 설명할 수 있다
  • Bottleneck 블록 안에서 stride가 왜 1×1이 아니라 3×3 conv에 적용되는지 설명할 수 있다
  • 56→28→14→7로 이어지는 3단계 절반 축소를 직접 손계산으로 재현할 수 있다
  • 224에서 7까지 줄어드는 데 몇 번의 stride=2가 필요한지, $224/2^n=7$ 관계로 설명할 수 있다
  • Projection shortcut이 왜 필요한지(본류와 크기·채널을 맞추기 위함) 설명할 수 있다
  • Receptive Field 누적 공식을 이용해 두 층을 통과한 뒤의 RF를 손계산할 수 있다

t검정(Student's t-test) 완전정복

t분포는 왜 정규분포보다 꼬리가 두꺼운가부터 3가지 t검정의 원리·손계산·실전 문제까지

0t분포는 어디서 오는가

0.1 문제의 출발점 — 모분산을 모른다

표본평균을 표준화할 때 원래는 모표준편차 σ가 필요하다.

\[ Z = \frac{\bar x - \mu}{\sigma/\sqrt n} \sim N(0,1) \]

하지만 현실에서는 σ를 모르는 경우가 대부분이다. 그래서 표본표준편차 s로 σ를 대체하는데, s 자체도 표본마다 흔들리는 확률변수이므로, 이 흔들림까지 반영하면 더 이상 정규분포가 아니라 꼬리가 더 두꺼운 분포가 된다. 이것이 t분포다.

\[ t = \frac{\bar x - \mu}{s/\sqrt n} \sim t_{(n-1)} \]

0.2 수학적 정의

표준정규분포 Z와, Z와 독립인 자유도 k인 카이제곱분포 \(\chi^2_{(k)}\)가 있을 때, 다음과 같이 정의되는 확률변수가 자유도 k인 t분포를 따른다.

\[ t = \frac{Z}{\sqrt{\chi^2_{(k)}/k}} \sim t_{(k)} \]

표본평균의 표준화식 \(t=(\bar x-\mu)/(s/\sqrt n)\)에서 분자는 표준정규(Z), 분모의 s는 표본분산에서 나오는데 \((n-1)s^2/\sigma^2\)이 카이제곱분포를 따른다는 사실(카이제곱검정 학습서 5장 참고)을 이용하면 정확히 위 정의와 일치한다. 즉 t분포는 "표준정규를 카이제곱의 제곱근으로 나눈 것"이며, 분모의 불확실성(표본마다 s가 흔들림) 때문에 극단값이 더 자주 나타난다.

0.3 자유도에 따른 형태 변화

경험칙: 자유도가 30 이상이면 t분포와 표준정규분포의 차이가 실무적으로 무시할 만큼 작아진다. 그래서 대표본(n≥30)에서는 Z검정을 근사로 사용하기도 한다.

2단일표본 t검정 (One-sample t-test)

2.1 원리

표본평균 x̄가 특정 기준값(모평균 후보) μ0과 유의하게 다른지 검정한다.

\[ H_0: \mu = \mu_0 \qquad H_1: \mu \neq \mu_0\ (\text{또는}\ \gt,\ \lt) \] \[ t = \frac{\bar x - \mu_0}{s/\sqrt n},\quad df = n-1 \]

2.2 손계산 예제

[문제] 배터리 수명이 평균 10시간이라 광고. 표본 n=16, x̄=9.4, s=1.6. 광고가 맞는지 α=.05 양측검정 [Step1] SE = s/√n = 1.6/√16 = 1.6/4 = 0.4 [Step2] t = (9.4-10)/0.4 = -0.6/0.4 = -1.5 [Step3] df=15, t(0.025,15)=±2.131 [Step4] |-1.5| < 2.131 → 기각역 밖 [결론] H0 기각 못함 → 배터리 수명이 10시간이 아니라고 할 근거 없음

3독립표본 t검정 (Independent two-sample t-test)

3.1 원리 — 등분산 vs 이분산

서로 독립인 두 그룹의 평균 차이를 검정한다. 두 그룹의 모분산이 같다고 가정할 수 있는지(등분산성, F검정으로 사전 확인 가능)에 따라 공식이 달라진다.

\[ H_0: \mu_1=\mu_2 \qquad H_1: \mu_1\neq\mu_2 \] \[ \text{등분산 가정(Student's t): } t=\frac{\bar x_1-\bar x_2}{\sqrt{s_p^2\left(\frac1{n_1}+\frac1{n_2}\right)}},\ \ s_p^2=\frac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2-2},\ \ df=n_1+n_2-2 \] \[ \text{이분산 가정(Welch's t): } t=\frac{\bar x_1-\bar x_2}{\sqrt{\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}}},\ \ df\approx\frac{\left(\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1-1}+\frac{(s_2^2/n_2)^2}{n_2-1}} \]

3.2 손계산 예제 — 등분산 가정 (Student's t)

[문제] A반(n1=10) 평균 78, 분산 16 / B반(n2=12) 평균 74, 분산 20. 사전 F검정으로 등분산 확인됨 [Step1] 합동분산 sp² = [(10-1)*16 + (12-1)*20] / (10+12-2) = (144+220)/20 = 18.2 [Step2] SE = √(18.2*(1/10+1/12)) = √(18.2*0.1833) = √3.337 = 1.827 [Step3] t = (78-74)/1.827 = 2.19, df=20 [Step4] t(0.025,20)=2.086 → |2.19| > 2.086 [결론] H0 기각 → 두 반의 평균은 유의하게 다르다

3.3 손계산 예제 — 이분산 가정 (Welch's t)

[문제] 그룹1(n1=8, x̄=50, s1²=36) / 그룹2(n2=15, x̄=44, s2²=9). 분산이 크게 다름(이분산) [Step1] SE = √(36/8 + 9/15) = √(4.5+0.6) = √5.1 = 2.258 [Step2] t = (50-44)/2.258 = 2.657 [Step3] Welch-Satterthwaite df ≈ [(4.5+0.6)²] / [(4.5²/7)+(0.6²/14)] = 26.01 / [2.893+0.0257] = 26.01/2.918 = 8.9 ≈ 9 [Step4] t(0.025, df≈9) = 2.262 → 2.657 > 2.262 [결론] H0 기각 → 두 그룹 평균은 유의하게 다르다
두 그룹의 표본크기와 분산이 모두 비슷하지 않다면 등분산을 가정하는 Student's t보다 Welch's t를 기본으로 사용하는 것이 안전하다는 것이 최근 통계 실무의 권고사항이다(등분산일 때도 Welch's t의 검정력 손실이 거의 없음).

4대응표본 t검정 (Paired t-test)

4.1 원리

같은 대상을 두 번 측정(사전-사후, 좌우, 처치 전후 등)하여 짝지어진 데이터일 때 사용한다. 두 측정값의 차이(d) 하나의 표본으로 변환하여 단일표본 t검정과 동일한 논리로 계산한다.

\[ H_0: \mu_d = 0 \qquad H_1: \mu_d \neq 0 \] \[ d_i = x_{i,\text{후}} - x_{i,\text{전}} \qquad t = \frac{\bar d}{s_d/\sqrt n},\quad df=n-1 \]

4.2 손계산 예제

[문제] 다이어트 프로그램 전후 체중(kg), n=6 전: 80, 75, 90, 85, 78, 88 후: 76, 74, 85, 84, 75, 82 [Step1] 차이 d = 후-전 = -4, -1, -5, -1, -3, -6 [Step2] d̄ = (-4-1-5-1-3-6)/6 = -20/6 = -3.333 [Step3] 편차제곱: (−4+3.33)²=0.444, (−1+3.33)²=5.444, (−5+3.33)²=2.778, (−1+3.33)²=5.444, (−3+3.33)²=0.111, (−6+3.33)²=7.111 합=21.33, s_d² = 21.33/5 = 4.267, s_d=2.066 [Step4] t = -3.333 / (2.066/√6) = -3.333 / 0.8435 = -3.95 [Step5] df=5, t(0.025,5)=2.571 → |-3.95| > 2.571 [결론] H0 기각 → 다이어트 프로그램 전후 체중 차이는 통계적으로 유의함
대응표본 t검정은 개체 간 편차(예: 원래 체중이 무거운 사람 vs 가벼운 사람의 차이)를 제거하고 순수하게 "처치 효과"만 검정하기 때문에, 같은 표본크기라면 독립표본 t검정보다 검정력이 높다.

5.1 t검정의 전제조건

조건설명확인 방법
정규성모집단(또는 차이값)이 정규분포를 따름Shapiro-Wilk, Q-Q plot
독립성관측치들이 서로 독립(대응표본은 쌍 내에서는 예외)연구 설계로 확보
등분산성(독립표본만)두 그룹의 모분산이 동일F검정, Levene 검정
척도연속형(등간·비율) 척도자료수집 설계
표본크기가 충분히 크면(n≥30 정도) 중심극한정리에 의해 정규성 가정이 다소 깨져도 t검정이 비교적 안정적으로 작동한다(강건성, robustness). 하지만 표본이 작고 정규성이 심하게 깨졌다면 비모수 검정으로 전환해야 한다.

5.1a F검정을 독립표본 t검정의 사전단계로 사용하기

독립표본 t검정은 등분산 가정 여부에 따라 Student's t(합동분산 사용, df=n1+n2-2)와 Welch's t(각 분산을 그대로 사용, df는 근사식)로 공식이 달라진다. 등분산 여부를 객관적으로 판단하는 표준적 방법이 바로 F검정이며, 아래처럼 "F검정 → 등분산 판정 → t검정 공식 선택 → t검정 수행"의 4단계로 이어진다.

5.1b 손계산 예제 — F검정 → 등분산 판정 → t검정까지 한번에

[문제] A그룹(n1=10) 표본분산 s1²=25 / B그룹(n2=8) 표본분산 s2²=6. 두 그룹의 모분산이 같은지 확인 후 독립표본 t검정을 수행한다. A그룹 평균 x̄1=52, B그룹 평균 x̄2=46, α=.05(양측) ━━━ Step A. 등분산성 F검정 ━━━ [A-1] 관례상 큰 분산을 분자에 둔다: F = s1²(큰쪽)/s2²(작은쪽) = 25/6 = 4.17 [A-2] 자유도: df1=n1-1=9 (분자쪽), df2=n2-1=7 (분모쪽) [A-3] 양측검정이므로 상위 임계값 F(0.025, 9, 7) ≈ 4.82 를 사용 [A-4] 4.17 < 4.82 → 기각역 밖 → H0(등분산) 기각 못함 [A-결론] 두 그룹은 등분산으로 볼 수 있다 → Student's t(합동분산) 공식 사용 결정 ━━━ Step B. Student's t 공식으로 t검정 수행 ━━━ [B-1] 합동분산 sp² = [(n1-1)s1² + (n2-1)s2²] / (n1+n2-2) = [9*25 + 7*6] / (10+8-2) = [225+42]/16 = 267/16 = 16.6875 [B-2] SE = √(sp² * (1/n1 + 1/n2)) = √(16.6875 * (0.1+0.125)) = √(16.6875 * 0.225) = √3.755 = 1.938 [B-3] t = (x̄1-x̄2) / SE = (52-46) / 1.938 = 6/1.938 = 3.10 [B-4] df = n1+n2-2 = 16, t(0.025, 16) = 2.120 [B-결론] |3.10| > 2.120 → H0(μ1=μ2) 기각 → 두 그룹 평균은 통계적으로 유의하게 다르다
만약 Step A에서 F값이 임계값을 넘어 등분산 가정이 기각되었다면, Step B는 합동분산 sp² 대신 각 그룹의 분산(s1², s2²)을 그대로 쓰는 Welch's t 공식(3.1 참고)과 Welch-Satterthwaite 근사자유도로 넘어가야 한다.

5.3 검정력에 영향을 주는 요인

\[ \text{검정력에 영향: 표본크기}\ n\ \uparrow,\ \text{효과크기(평균차)}\ \uparrow,\ \text{유의수준}\ \alpha\ \uparrow,\ \text{분산}\ \sigma^2\ \downarrow \ \Rightarrow\ \text{검정력}\ (1-\beta)\ \uparrow \]

t검정을 설계하기 전에 사전 검정력 분석(power analysis)으로 필요한 최소 표본크기를 계산하는 것이 좋은 실무 습관이다. Cohen's d(효과크기)를 기준으로 계산한다.

\[ \text{Cohen's d} = \frac{\bar x_1-\bar x_2}{s_p} \quad (0.2\text{=작음},\ 0.5\text{=중간},\ 0.8\text{=큼}) \]

# 배터리 수명 예제 (2장) from scipy.stats import ttest_1samp data = [9.5, 9.1, 8.8, 10.2, 9.4, 9.0, 9.9, 8.6, 9.7, 9.3, 8.9, 10.0, 9.6, 9.2, 9.8, 8.7] # 예시 데이터(n=16) stat, p = ttest_1samp(data, popmean=10) print(f"t={stat:.3f}, p={p:.4f}")

6.2 독립표본 t검정 (등분산/이분산)

# A반, B반 예제 (3장) from scipy.stats import ttest_ind, levene groupA = [82, 79, 75, 80, 77, 81, 78, 76, 83, 80] groupB = [70, 74, 76, 72, 75, 73, 71, 77, 74, 72, 76, 73] # 사전 등분산검정 (Levene) lstat, lp = levene(groupA, groupB) print(f"Levene p={lp:.4f}") # p<.05면 등분산 가정 기각 # 등분산 가정 (Student's t) t1, p1 = ttest_ind(groupA, groupB, equal_var=True) # 이분산 가정 (Welch's t) — 기본값 권장 t2, p2 = ttest_ind(groupA, groupB, equal_var=False) print(f"Student t={t1:.3f}, p={p1:.4f} / Welch t={t2:.3f}, p={p2:.4f}")

6.3 대응표본 t검정

# 다이어트 전후 체중 예제 (4장) from scipy.stats import ttest_rel before = [80, 75, 90, 85, 78, 88] after = [76, 74, 85, 84, 75, 82] stat, p = ttest_rel(after, before) print(f"t={stat:.3f}, p={p:.4f}") # t=-3.950, p≈0.0108 → 앞선 손계산과 일치
ttest_ind는 기본값이 equal_var=True지만, 실무에서는 먼저 levene()으로 등분산을 확인하거나, 아예 equal_var=False(Welch's t)를 기본으로 쓰는 것을 권장한다.

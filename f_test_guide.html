0F분포는 어디서 오는가

0.1 정의

서로 독립인 두 카이제곱분포 \(\chi^2_{(d_1)}\), \(\chi^2_{(d_2)}\)를 각각 자유도로 나눈 값의 비율이 F분포를 따른다.

\[ F = \frac{\chi^2_{(d_1)}/d_1}{\chi^2_{(d_2)}/d_2} \sim F_{(d_1,\,d_2)} \]

t분포가 "표준정규 하나를 카이제곱의 제곱근으로 나눈 것"이었다면, F분포는 "카이제곱 두 개의 비율"이다. 두 그룹의 분산비, ANOVA의 집단간/집단내 변동비, 회귀모형의 설명변동/잔차변동비가 모두 이 구조(변동을 자유도로 나눈 것끼리의 비율)를 갖기 때문에 F분포를 따른다.

0.2 형태의 특징

\[ E(F) = \frac{d_2}{d_2-2}\ (d_2>2) \qquad Var(F)=\frac{2d_2^2(d_1+d_2-2)}{d_1(d_2-2)^2(d_2-4)}\ (d_2>4) \]
F분포의 평균이 항상 1보다 크고 분모의 자유도(d2)에만 의존한다는 점이 흥미롭다. 두 변동이 정말 같다면(H0 참) F는 1 근처에 몰리지만, 완전한 대칭은 아니고 약간 1보다 큰 쪽에 평균이 위치한다.
Q. F분포가 항상 0 이상의 값만 가지는 이유는?
PART 1 — F검정 (통계적 검정으로서의 F)

1F검정의 4가지 얼굴

F검정은 "두 집단 분산 비교" 하나만을 가리키지 않는다. 두 변동(또는 두 분산)의 비율이 F분포를 따르는 모든 검정을 통칭한다. "분산비 = 1인가?"라는 동일한 논리가 여러 국면에서 반복된다.

2등분산검정 — 두 집단 분산 비교

2.1 원리

독립표본 t검정 전 단계로, 두 그룹의 모분산이 같은지 확인한다.

\[ H_0: \sigma_1^2=\sigma_2^2 \qquad F=\frac{s_1^2}{s_2^2}\sim F_{(n_1-1,\,n_2-1)}\quad(\text{관례상 } s_1^2\ge s_2^2 \text{ 로 } F\ge1) \]

2.2 손계산 예제

[문제] A그룹(n1=13) 분산 s1²=25 / B그룹(n2=10) 분산 s2²=9. 등분산인가? (α=.05) [Step1] F = 25/9 = 2.78, df1=12, df2=9 [Step2] 양측검정이므로 상위 임계값 F(0.025,12,9) ≈ 3.87 [Step3] 2.78 < 3.87 → 기각역 밖 [결론] H0 기각 못함 → 등분산으로 볼 수 있음, 이후 t검정에서 합동분산 사용 가능
F검정은 정규성 가정에 매우 민감하다. 정규성이 조금만 깨져도 1종 오류가 크게 부풀려지므로, 정규성이 불확실할 때는 Levene 검정(정규성 불필요, 실무 기본값)을 대신 사용하는 것이 안전하다.
Q. 등분산검정의 F값은 관례상 어떻게 계산하는가?

3ANOVA F검정 — 3집단 이상 평균 비교

3.1 원리

전체 변동을 집단간 변동(SSB)과 집단내 변동(SSW)으로 분해해 그 비율을 검정한다. "평균의 차이"를 "분산의 비율"로 바꿔 한 번에 검정하는 것이 핵심 아이디어다.

\[ F=\frac{MSB}{MSW}=\frac{SSB/(k-1)}{SSW/(N-k)}\sim F_{(k-1,\,N-k)} \]

3.2 손계산 예제

[문제] 3개 비료(A,B,C) 각 3개 표본 수확량: A(4,5,6) B(7,8,9) C(10,11,12) [Step1] 그룹평균: Ā=5,B̄=8,C̄=11, 전체평균Ḡ=8 [Step2] SSB = 3*(5-8)²+3*(8-8)²+3*(11-8)² = 27+0+27 = 54 [Step3] SSW = (1+0+1)*3 = 6 [Step4] MSB=54/2=27, MSW=6/6=1, F=27/1=27 [Step5] F(0.05,2,6)=5.14 → 27 > 5.14 [결론] H0 기각 → 비료 종류에 따라 수확량 평균이 유의하게 다름 (사후검정으로 어느 쌍이 다른지 추가 확인 필요)

4회귀모형 F검정 — 모형 전체의 유의성

4.1 원리

회귀모형이 변수를 하나도 쓰지 않는 것보다 유의하게 설명력이 있는지 검정한다. 개별 계수의 유의성은 t검정이지만, "모형 전체"가 의미 있는지는 F검정으로 판단한다.

\[ H_0:\beta_1=\beta_2=\cdots=\beta_p=0 \qquad F=\frac{MSR}{MSE}=\frac{SSR/p}{SSE/(n-p-1)}\sim F_{(p,\,n-p-1)} \]

4.2 손계산 예제

[문제] n=25, 독립변수 p=3개. SSR=180, SSE=60. 모형이 유의한가?(α=.05) [Step1] df1=p=3, df2=n-p-1=25-3-1=21 [Step2] MSR=180/3=60, MSE=60/21=2.857 [Step3] F = 60/2.857 = 21.0 [Step4] F(0.05,3,21) ≈ 3.07 → 21.0 > 3.07 [결론] H0 기각 → 회귀모형은 통계적으로 유의함(적어도 하나의 변수는 설명력이 있음)
모형 F검정이 유의하다고 해서 모든 변수가 유의한 것은 아니다. 어떤 변수가 유의한지는 각 회귀계수의 t검정으로 개별 확인해야 한다.

5중첩모형 비교 F검정 (Partial F-test)

5.1 원리

변수를 추가하기 전(축소모형)과 추가한 후(확장모형)의 SSE 감소량이 통계적으로 유의한지 검정한다. 새로 추가한 변수(들)가 정말 설명력을 개선하는지 판단하는 근거이며, Stepwise 변수선택의 이론적 기반이다.

\[ F=\frac{(SSE_{\text{축소}}-SSE_{\text{확장}})/q}{SSE_{\text{확장}}/(n-p-1)}\sim F_{(q,\,n-p-1)} \]

q: 새로 추가된 변수의 개수, p: 확장모형의 전체 변수 개수

5.2 손계산 예제

[문제] n=30. 축소모형(변수2개) SSE=90 / 확장모형(변수5개, 3개 추가) SSE=60. 추가한 3개 변수가 유의한가? [Step1] q=3(추가 변수 수), p=5(확장모형 변수 수), df2=n-p-1=30-5-1=24 [Step2] F = [(90-60)/3] / [60/24] = 10 / 2.5 = 4.0 [Step3] F(0.05,3,24) ≈ 3.01 → 4.0 > 3.01 [결론] H0 기각 → 새로 추가한 3개 변수는 전체적으로 유의한 설명력 향상을 가져옴
Q. 변수 2개를 추가한 확장모형과 축소모형을 비교하는 Partial F-test의 분자 자유도(q)는?

6전제조건과 주의사항

조건설명
정규성각 집단(또는 잔차)이 정규분포를 따라야 함 — F검정은 특히 민감
독립성관측치들이 서로 독립
척도연속형(등간·비율) 척도
등분산 비교가 목적이면서 정규성이 불확실할 때는 Levene 검정(중앙값 기준이면 더 강건, Brown-Forsythe라고도 함)이나 Bartlett 검정(정규성 가정, 3집단 이상 확장 가능)을 대안으로 고려한다. ANOVA·회귀모형 F검정은 잔차의 정규성·등분산성(Q-Q plot, 잔차 vs 적합값 플롯)을 함께 점검하는 것이 표준 실무다.
PART 2 — scipy.stats.f 함수로 F분포 다루기

7scipy.stats.f 7개 함수 전체 지도

t분포·카이제곱분포와 마찬가지로, 모든 함수는 F값 → 확률로 가는 함수(pdf, cdf, sf)와 확률 → F값으로 거꾸로 가는 함수(ppf, isf)로 나뉜다.

함수입력출력한 줄 의미
pdf(x, d1, d2)F값밀도그 지점의 곡선 높이
cdf(x, d1, d2)F값누적확률P(F ≤ x)
sf(x, d1, d2)F값꼬리확률P(F > x) = 1-cdf(x), 검정의 p-value로 직결
ppf(q, d1, d2)누적확률 qF값cdf의 역함수, 기각역 경계(임계값)
isf(q, d1, d2)꼬리확률 qF값sf의 역함수, ppf(1-q)와 동일한 값
interval(a, d1, d2)중심확률 a(하한,상한)비대칭 구간 — F분포는 좌우대칭이 아님에 주의
stats(d1,d2,'mv')자유도쌍(평균,분산)분포 전체 요약값
t·카이제곱과 달리 F분포는 자유도가 (d1, d2) 두 개다. 함수 호출 시 항상 분자 자유도, 분모 자유도 순서로 넣어야 한다.

8pdf(x, d1, d2) — 확률밀도함수

F=x 지점에서 곡선의 높이(밀도)를 반환한다. F분포는 비대칭(오른쪽 꼬리가 긴) 형태이므로, 곡선의 정점(mode)이 F=1보다 왼쪽에 위치하는 경우가 많다.

\[ f(x;d_1,d_2)=\frac{\sqrt{\frac{(d_1x)^{d_1}d_2^{d_2}}{(d_1x+d_2)^{d_1+d_2}}}}{x\,B\!\left(\frac{d_1}{2},\frac{d_2}{2}\right)} \qquad \text{mode} = \frac{d_2(d_1-2)}{d_1(d_2+2)}\ (d_1>2) \]
Q. F분포의 최빈값(mode)이 항상 F=1인가?

9cdf(x, d1, d2) — 누적분포함수

0부터 F=x까지 곡선 아래 면적, 즉 P(F ≤ x)를 반환한다.

9.1 손계산 예제 (근사)

[문제] d1=5,d2=10에서 F분포표로 cdf(3.33,5,10)을 근사하시오 [Step1] F분포표에서 F(0.05,5,10)=3.33을 찾음(상위 5% 지점) [Step2] 즉 P(F>3.33)=0.05 [결론] cdf(3.33,5,10) = 1-0.05 = 0.95

10sf(x, d1, d2) — 생존함수(p-value 직결)

F=x부터 오른쪽 끝까지의 면적, 즉 P(F > x). F검정은 거의 항상 단측(오른쪽 꼬리) 검정이므로, sf 값이 바로 p-value가 되는 경우가 많다.

10.1 손계산 예제 — ANOVA의 p-value

[문제] 3장의 비료 예제: F=27, df1=2, df2=6. p-value는? [Step1] p-value = P(F > 27) = sf(27, 2, 6) [Step2] scipy 계산 결과 sf(27,2,6) ≈ 0.00098 [결론] p ≈ 0.001 < .05 → H0 기각 (매우 강한 증거)
F검정은 (등분산검정을 제외하면) 대체로 오른쪽 꼬리만 사용하는 단측검정이다. 변동비가 1보다 훨씬 크다는 것만 "차이가 있다"는 증거가 되기 때문이다.

11ppf(q, d1, d2) / isf(q, d1, d2) — 임계값 찾기

확률을 알 때 F값을 역산한다. 검정의 기각역 경계(임계값)를 구하는 표준적인 방법이다.

\[ \text{ppf}(1-\alpha,\,d_1,d_2) = \text{isf}(\alpha,\,d_1,d_2) = F_{(\alpha,\,d_1,d_2)} \]

11.1 손계산 예제

[문제] d1=3, d2=21, α=.05 단측검정의 임계값을 구하시오 [Step1] ppf(0.95, 3, 21) 또는 isf(0.05, 3, 21) — 둘 다 같은 값 [Step2] F분포표에서 F(0.05,3,21) 확인 [결론] 임계값 ≈ 3.07 (4장 회귀모형 예제의 임계값과 일치)
Q. isf(0.025, 4, 20)와 같은 값을 반환하는 것은?

12interval(alpha, d1, d2) — 비대칭 신뢰구간

중심 확률 α를 포함하는 구간의 (하한, 상한)을 반환한다. F분포는 좌우대칭이 아니므로 t분포의 interval과 달리 하한과 상한이 중심에서 대칭이 아니다 — 하한은 0에 가깝고 상한은 멀리 떨어져 있다.

그림에서 보듯 하한까지의 거리는 짧고 상한까지의 거리는 길다 — 이것이 F분포가 비대칭임을 보여주는 시각적 증거다. t분포의 interval처럼 "평균 ± 오차범위" 식으로 단순화할 수 없다.
Q. t분포의 interval(0.95, df)과 F분포의 interval(0.95, d1, d2)의 가장 큰 차이는?

13stats(d1, d2, moments='mv') — 분포 요약통계

\[ E(F)=\frac{d_2}{d_2-2}\ (d_2>2) \qquad Var(F)=\frac{2d_2^2(d_1+d_2-2)}{d_1(d_2-2)^2(d_2-4)}\ (d_2>4) \]

13.1 손계산 예제

[문제] d1=4, d2=20일 때 F분포의 평균과 분산은? [평균] E(F) = 20/(20-2) = 20/18 = 1.111 [분산] Var(F) = 2*20²*(4+20-2) / [4*(20-2)²*(20-4)] = 2*400*22 / [4*324*16] = 17600/20736 = 0.849 [결론] d2(분모 자유도)가 커질수록 평균은 1에 가까워지고 분산도 작아진다
d2 ≤ 2이면 평균이, d2 ≤ 4이면 분산이 정의되지 않는다(발산). 분모 쪽 자유도가 작은 F분포를 다룰 때 특히 주의해야 한다.

14Python(scipy) 실전 코드 종합

14.1 등분산검정 (Levene 포함)

# 2장 예제 from scipy.stats import f, levene import numpy as np groupA = [80,78,82,85,79,88,81,83,86,84,87,90,89] # n1=13 groupB = [70,72,74,68,73,71,69,75,72,70] # n2=10 var1, var2 = np.var(groupA, ddof=1), np.var(groupB, ddof=1) F_stat = max(var1,var2) / min(var1,var2) df1, df2 = len(groupA)-1, len(groupB)-1 p_value = 2 * f.sf(F_stat, df1, df2) # 양측검정 print(f"F={F_stat:.3f}, p={p_value:.4f}") # 정규성이 불확실하면 Levene 검정 권장 lstat, lp = levene(groupA, groupB) print(f"Levene p={lp:.4f}")

14.2 ANOVA F검정

# 3장 비료 예제 from scipy.stats import f_oneway A, B, C = [4,5,6], [7,8,9], [10,11,12] stat, p = f_oneway(A, B, C) print(f"F={stat:.2f}, p={p:.5f}") # F=27.00, p≈0.00098

import statsmodels.api as sm X = sm.add_constant(X_data) # X_data: 독립변수 행렬 model = sm.OLS(y_data, X).fit() print(model.fvalue, model.f_pvalue) # 4장의 F, p-value에 해당

14.4 F분포 함수 7종 한번에

d1, d2 = 3, 21 print("pdf(1,3,21) :", f.pdf(1, d1, d2)) print("cdf(3.07,3,21) :", f.cdf(3.07, d1, d2)) print("sf(3.07,3,21) :", f.sf(3.07, d1, d2)) print("ppf(0.95,3,21) :", f.ppf(0.95, d1, d2)) print("isf(0.05,3,21) :", f.isf(0.05, d1, d2)) print("interval(.9,..) :", f.interval(0.90, d1, d2)) print("stats(mv) :", f.stats(d1, d2, moments='mv'))

AI 모델 아키텍처의 계보

MLP → CNN → RNN → Attention까지, "왜" 구조가 바뀌었는가를 중심으로

원문: Yang Kewen, "A Brief History Of AI Models — Part I" (Medium, 2023.09) 내용을 재구성·확장한 학습서

MLP · GLM CNN · Convolution RNN · Unrolling Bahdanau Attention

1왜 아키텍처는 계속 바뀌는가

딥러닝 모델의 역사를 처음 접하면 MLP, CNN, RNN, Attention, Transformer 같은 용어들이 각각 독립적으로 등장한 것처럼 느껴지기 쉽습니다. 하지만 실제로는 이전 구조가 특정 데이터(이미지, 텍스트)를 처리할 때 부딪힌 구체적인 한계를 해결하기 위해 다음 구조가 순차적으로 고안된, 하나의 연속된 이야기입니다.

이 학습서는 그 흐름을 "무엇이 문제였고, 그래서 무엇을 새로 도입했는가"라는 질문을 축으로 따라갑니다:

핵심 흐름
MLP (모든 입력을 평평하게 처리) → 이미지에서 한계 → CNN (공간 정보 보존) → 텍스트에서 한계 → RNN (순서 정보 처리) → 장기 의존성 문제 → Attention (문맥에 따라 가중치 부여)

2MLP — 최초의 신경망

다층 퍼셉트론(Multilayer Perceptron, MLP)은 전통적인 통계·머신러닝 모델(다중선형회귀, 그래디언트 부스팅 등)보다 훨씬 복잡하고 연산량이 많은 구조로, 딥러닝의 출발점으로 꼽힙니다.

2-1. 통계학적 관점: GLM과의 유사성

통계학을 공부한 사람의 시각에서 보면, MLP의 뉴런 하나는 일반화선형모형(Generalized Linear Model, GLM)과 구조적으로 닮아 있습니다. GLM은 1972년에 처음 제안된 개념으로, 선형결합의 결과를 연결함수(link function)를 통해 비선형 반응변수로 변환합니다.

$$ g(E[y]) = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_n x_n $$

여기서 연결함수 $g(\cdot)$의 역함수가 바로 MLP 뉴런의 활성화 함수(activation function)에 대응합니다. 즉 "선형결합 + 비선형변환"이라는 골격 자체는 GLM 시대부터 이미 있었고, MLP는 이 구조를 여러 층으로 쌓아 올린 것으로 이해할 수 있습니다.

2-2. 순전파 (Forward Propagation)

MLP의 뉴런 하나를 특징 추출기(feature extractor)로 볼 수 있습니다. 입력 변수 $x_1, x_2, x_3$가 들어오면:

  1. 먼저 선형결합으로 입력들의 선형적 특성을 포착합니다.
  2. 이어서 활성화 함수가 그 결과의 비선형적 특성을 포착해 최종 출력 $\hat{y}$(y-hat)을 만듭니다.

통계학에서 "hat" 기호는 관례적으로 확률변수의 추정값을 의미합니다 — 즉 $\hat{y}$는 신경망이 내놓은 예측값입니다.

2-3. 역전파 (Backward Propagation)

예측값 $\hat{y}$을 얻으면 실제값 $y$와 비교해 오차를 계산합니다. MLP의 목표는 이 오차를 최소화하는 것이므로, 경사하강법(gradient descent)으로 손실함수의 전역 최소점을 찾아갑니다. 이 과정에서 오차를 출력층에서 입력층 방향으로 거슬러 전파하며 각 가중치의 기울기를 계산하는 절차가 역전파입니다.

3MLP의 한계

MLP는 전통적인 머신러닝 모델보다 나은 성능을 보여줬지만, 연구자들은 곧 다음과 같은 구조적 약점을 발견했습니다.

한계구체적 설명
이미지 처리에 취약객체 간 공간적 관계를 학습하기 어렵고, 픽셀 수가 많아지면 연산 효율이 급격히 떨어짐
이동 불변성(translation invariance) 부재같은 고양이라도 이미지 상단/하단 어디에 있는지에 따라 예측 결과가 달라짐
문맥 이해 부족입력을 순서 없는 평평한 벡터로 취급하므로 단어/픽셀 간 맥락을 반영하지 못함
고정된 입력 크기가변 길이 문장이나 가변 해상도 이미지를 다루기 어려움

이 중 앞의 두 가지(공간 관계, 이동 불변성)를 해결하기 위해 등장한 것이 CNN이고, 뒤의 두 가지(문맥, 가변 길이)를 해결하기 위해 등장한 것이 RNN입니다 — 즉 하나의 문제의식이 두 갈래의 구조로 갈라져 발전했다고 볼 수 있습니다.

4CNN — 이미지를 위한 구조

CNN(합성곱 신경망)의 핵심은 합성곱 층(convolutional layer)으로, 시각적 특징을 추출하는 역할을 합니다. 커널(kernel)이라는 작은 필터가 이미지 위를 일정한 보폭(stride)으로 이동하며, 그때마다 겹치는 픽셀 영역의 정보를 하나의 값으로 요약합니다. 이 과정을 거치면 원본 이미지보다 작은 특성 맵(feature map)이 만들어집니다.

이미지의 정보를 더 폭넓게 포착하기 위해, 보통 하나의 이미지에 여러 개의 커널을 동시에 적용해 여러 장의 특성 맵을 만듭니다. 이렇게 얻어진 특성 맵들을 평탄화(flatten)한 뒤 피드포워드 층(사실상 MLP)에 입력해 분류나 회귀 작업을 수행합니다.

5RNN 등장 배경 — 텍스트 문제

합성곱 층 덕분에 이미지 처리에서의 MLP 한계는 상당 부분 해소되었지만, 자연어 처리(NLP)에서는 여전히 다른 종류의 문제가 남아 있었습니다.

  • 문장 속 단어들 사이의 문맥은 기계 독해에서 매우 중요한데, MLP나 CNN은 이를 제대로 포착하지 못함
  • 기계 번역과 같은 작업에서는 입력과 출력의 길이가 고정되어 있지 않음 — 문장마다 단어 수가 다름

이 문제들을 풀기 위해 연구자들이 도입한 것이 순환 신경망(Recurrent Neural Network, RNN)입니다.

6RNN 구조와 순환 메커니즘

RNN 한 층은 이름과 달리 여러 개의 뉴런이 아니라 단 하나의 뉴런(셀)으로 구성되며, 이 셀이 시간 축을 따라 반복적으로 재사용됩니다. 많은 자료에서 RNN을 "펼친(unrolled)" 형태로 그리는데, 이는 시계열 순환 구조를 시간 순서에 따라 하나의 일직선 그래프로 풀어서 표현한 것일 뿐, 실제로 뉴런이 여러 개 있는 것은 아닙니다.

RNN의 순환 구조를 좌에서 우로 읽으면, 이전 시점의 입력 텍스트 $x^{\langle t-1\rangle}$와 이전 은닉상태 $a^{\langle t-1\rangle}$가 현재 시점의 출력 텍스트 $y^{\langle t\rangle}$와 은닉상태 $a^{\langle t\rangle}$를 만드는 데 사용됩니다. 여기서 "시간 스텝(time step)"은 문장 속 단어의 위치 인덱스라고 이해하면 됩니다.

정리 — 단순 RNN은 입력 크기 제약과 문맥 이해 문제를 어느 정도 해결했지만, 완벽하지 않습니다. 다음 절에서 남은 두 가지 한계를 다룹니다.

7RNN의 두 가지 한계

한계설명
망각 문제 (Forgetting Problem) 은닉상태는 이전의 모든 단어 정보를 이론상 담고 있지만, 그 문맥 표현이 상대적으로 약하고 비효율적입니다. 문장이 길어질수록 앞부분의 정보가 점점 희석되어 "잊히는" 경향이 나타납니다.
병렬 연산 불가 출력 $y^{\langle t\rangle}$를 계산하려면 이전 은닉상태 $a^{\langle t-1\rangle}$와 현재 입력 $x^{\langle t\rangle}$가 모두 필요합니다. 즉 연산이 한 단어씩 순차적으로만 진행될 수 있어 GPU의 병렬 연산 이점을 활용하기 어렵고, 학습 속도가 느려집니다.

이 중 망각 문제를 해결하기 위해 2014년 Bahdanau가 제안한 것이 Attention 메커니즘입니다.

8Attention 메커니즘

Attention은 단순 RNN(또는 LSTM) 위에 추가되는 개선 장치로, 텍스트의 문맥 정보를 훨씬 효과적으로 포착할 수 있게 해줍니다. 기계 번역을 예로 들어 작동 원리를 살펴보겠습니다.

전체 과정을 4단계로 정리하면:

  1. Query 생성 — 디코더가 매 출력 단어를 하나의 쿼리(query) 벡터로 변환합니다.
  2. Key·Value 생성 — 인코더는 각 입력 단어를 키(key) 벡터와 값(value) 벡터 한 쌍으로 분해합니다.
  3. 가중치 계산 — 특정 쿼리가 주어지면, 인코더는 각 입력 단어에 가중치를 부여합니다. 이때 softmax를 적용하므로 한 쿼리에 대한 가중치의 합은 항상 1이 됩니다.
  4. 문맥 벡터 계산 — 3단계에서 구한 가중치와 대응하는 value 벡터들의 내적(dot product)을 통해, 디코더는 각 출력 단어에 대한 문맥 벡터(context vector)를 계산합니다.
핵심 아이디어 — 계산 과정 자체는 다소 복잡해 보이지만, 본질은 간단합니다: 특정 출력 단어를 기준으로 각 입력 단어에 얼마만큼의 중요도(가중치)를 부여할 것인가를 학습하는 것입니다. 입력 단어별 중요도를 구분함으로써, 모델은 상황에 따라 다른 부분에 다른 정도로 "주의(attention)"를 기울일 수 있게 됩니다.

8-1. Attention이 남긴 과제

Attention은 RNN의 망각 문제를 효과적으로 완화했습니다. 하지만 여전히 단순 RNN 구조 위에 얹혀 동작하기 때문에, attention 계산 자체의 연산 부담으로 학습 시간이 길어지고, RNN 특유의 순차 처리 방식 때문에 GPU 병렬화의 이점도 제대로 누리지 못합니다. 이 문제는 이후 RNN을 아예 걷어내고 Attention만으로 구성한 Transformer 구조로 이어집니다 (Part II에서 다룰 주제).

9아키텍처 계보 종합비교

구조해결한 문제핵심 메커니즘남은 한계
MLP비선형 패턴 학습 (전통 통계모델 대비)선형결합 + 활성화함수 (GLM의 확장)이미지 공간정보·가변입력·문맥 처리 불가
CNN이미지의 공간적 관계, 연산 효율합성곱 커널로 지역 특징 추출 → 특성맵텍스트의 순서·문맥·가변 길이 문제는 미해결
RNN가변 길이 입력, 순서 정보 처리은닉상태를 시간축을 따라 순환 전달망각 문제, 순차 처리로 인한 GPU 병렬화 불가
Attention (RNN 기반)장기 의존성·망각 문제Query-Key-Value 유사도 기반 가중치 + 문맥벡터여전히 RNN 위에서 동작 → 느린 학습, 병렬화 제약 지속

10학습 체크리스트

  • MLP 뉴런의 구조(선형결합 + 활성화함수)가 GLM의 연결함수 개념과 어떻게 대응하는지 설명할 수 있다
  • 순전파와 역전파의 역할 차이(예측 생성 vs. 오차를 이용한 가중치 갱신)를 설명할 수 있다
  • MLP가 이미지 처리에서 겪는 4가지 한계를 나열할 수 있다
  • 합성곱 연산에서 커널·스트라이드·특성맵의 관계를 설명할 수 있다
  • 왜 하나의 이미지에 여러 커널을 적용하는지 이유를 설명할 수 있다
  • RNN 한 층이 여러 뉴런이 아니라 하나의 셀이 시간축으로 재사용되는 구조임을 이해하고 있다
  • RNN의 망각 문제와 병렬 연산 불가 문제를 구분해서 설명할 수 있다
  • Attention의 Query·Key·Value 각각이 무엇을 나타내는지, softmax가 어디에 쓰이는지 설명할 수 있다
  • Attention이 RNN의 어떤 한계를 해결했고, 어떤 한계는 그대로 남겼는지 구분할 수 있다
  • MLP→CNN/RNN→Attention 전체 계보를 "문제→해결책" 흐름으로 요약해서 말할 수 있다

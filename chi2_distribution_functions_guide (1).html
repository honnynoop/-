0카이제곱분포 이론 — 정의부터 원리까지

0.1 정의 — 표준정규 제곱합

표준정규분포 \(N(0,1)\)를 따르는 서로 독립인 확률변수 \(Z_1, Z_2, \dots, Z_k\)가 있을 때, 이들의 제곱합은 자유도 k인 카이제곱분포를 따른다고 정의한다.

\[ \chi^2_{(k)} = Z_1^2+Z_2^2+\cdots+Z_k^2 = \sum_{i=1}^{k} Z_i^2,\qquad Z_i \overset{iid}{\sim} N(0,1) \]

즉 카이제곱분포는 그 자체로 새로 발명된 분포가 아니라, 표준정규분포에서 자연스럽게 파생되는 분포다. 편차를 표준화한 뒤 제곱해서 더하는 연산은 통계학 전반(분산 추정, 적합도 판정, 독립성 판정)에서 반복적으로 나타나기 때문에, 이 파생 분포에 별도의 이름과 표(table)를 붙여 놓은 것이라고 이해하면 된다.

0.2 왜 항상 0 이상이고 오른쪽으로 긴 꼬리를 갖는가

항상 0 이상인 이유

정의식 자체가 제곱들의 합이다. 각 \(Z_i^2 \ge 0\)이므로 아무리 값이 흩어져도 합은 결코 음수가 될 수 없다. 이 때문에 카이제곱분포는 좌측이 0에서 잘려나간(clipped) 형태를 가지며, 정규분포처럼 좌우로 무한히 뻗어나가지 않는다.

오른쪽 꼬리가 긴 이유

대부분의 \(Z_i\)는 0 근처에 몰려 있으므로(표준정규의 특성), 제곱합도 대개 작은 값 근처에 몰린다. 하지만 드물게 \(Z_i\)가 큰 값(예: ±3 이상)을 취하면 제곱되면서 그 영향이 급격히 커져 합계를 크게 밀어올린다. 이 비대칭적인 증폭 효과 때문에 오른쪽으로 긴 꼬리가 만들어진다.

0.3 감마분포와의 관계

카이제곱분포는 사실 감마분포(Gamma distribution)의 특수한 경우다. 형상모수(shape) \(=k/2\), 척도모수(scale) \(=2\)인 감마분포가 바로 자유도 k인 카이제곱분포와 정확히 같다.

\[ \chi^2_{(k)} \sim \text{Gamma}\!\left(\text{shape}=\tfrac{k}{2},\ \text{scale}=2\right) \] \[ f(x;k)=\frac{1}{2^{k/2}\Gamma(k/2)}\,x^{k/2-1}e^{-x/2},\qquad x\ge0 \]

이 관계 덕분에 카이제곱분포의 여러 성질(감마함수 기반 pdf, 재생성, 극한 거동)이 감마분포 이론에서 그대로 상속된다. 참고로 df=2인 카이제곱분포는 지수분포(평균 2)와 완전히 동일하다 — 감마분포에서 shape=1인 경우가 지수분포이기 때문이다.

0.4 재생성(가법성) — 왜 자유도를 그냥 더할 수 있는가

서로 독립인 두 카이제곱분포 \(X_1\sim\chi^2_{(k_1)}\), \(X_2\sim\chi^2_{(k_2)}\)가 있으면, 그 합은 다시 카이제곱분포를 따르며 자유도는 단순히 더해진다.

\[ X_1+X_2 \sim \chi^2_{(k_1+k_2)} \]

정의식(제곱합)을 생각하면 당연한 결과다 — 서로 다른 두 무리의 표준정규 제곱합을 합치면, 결국 더 많은 표준정규 확률변수들의 제곱합이 될 뿐이기 때문이다. 이 성질(가법성) 덕분에 독립성검정에서 여러 셀의 (O-E)²/E를 단순히 더해도 되는 이유, ANOVA에서 SST=SSB+SSW로 분해된 두 변동이 각각 카이제곱을 따르고 그 합도 카이제곱을 따르는 이유가 모두 설명된다.

0.5 자유도의 의미 — 표본분산과의 연결

정규모집단에서 뽑은 표본의 표본분산은 다음과 같이 카이제곱분포와 직접 연결된다(카이제곱 학습서 5장 모분산검정의 근거).

\[ \frac{(n-1)s^2}{\sigma^2} \sim \chi^2_{(n-1)} \]

왜 자유도가 n이 아니라 n-1인가? 표본분산을 계산할 때 모평균 μ 대신 표본평균 x̄를 사용하는데, n개의 편차 \((x_i-\bar x)\)는 합이 항상 0이 되도록 서로 묶여(제약되어) 있다. 즉 n개 중 n-1개가 정해지면 마지막 하나는 자동으로 결정된다 — "자유롭게 흩어질 수 있는" 정보의 개수가 n-1개라는 뜻이며, 이것이 자유도(degrees of freedom)라는 이름의 유래다.

0.6 평균·분산과 정규분포로의 수렴

\[ E(\chi^2_{(k)}) = k \qquad Var(\chi^2_{(k)}) = 2k \]

평균이 정확히 자유도 k와 같다는 점이 핵심이다 — 각 \(Z_i^2\)의 기댓값이 \(Var(Z_i)=1\)이므로, k개를 더하면 평균도 그대로 k가 된다. 또한 중심극한정리에 의해, k가 충분히 크면(대략 30 이상) 카이제곱분포는 평균 k, 분산 2k인 정규분포로 근사할 수 있다 — 이는 카이제곱분포 자체가 "많은 것을 더한 합"의 형태를 갖기 때문에 나타나는 자연스러운 결과다.

0.8 왜 카이제곱검정이 이 분포를 쓰는가 — 이론과 실전의 연결

카이제곱검정의 공통 공식 \(\sum(O-E)^2/E\)는 사실 "표준화된 편차의 제곱합"이라는 카이제곱분포의 정의와 정확히 같은 구조다. 각 범주(셀)의 (관측-기대)를 기대값의 제곱근으로 표준화하면 근사적으로 표준정규분포를 따르고, 그것을 제곱해서 모든 범주에 대해 더한 것이 바로 카이제곱 검정통계량이다. 즉 카이제곱검정은 0.1의 정의를 데이터에 그대로 적용한 것이며, 자유도는 0.5에서 본 "제약 조건으로 인해 자유롭게 흩어질 수 없는 개수"의 논리를 그대로 따른다 — 예를 들어 적합도검정의 df=k-1은 "전체 합이 n으로 고정된다"는 제약 하나가 자유도를 하나 깎아먹기 때문이다.

17개 함수 전체 지도

모든 함수는 χ²값 → 확률로 가는 함수(pdf, cdf, sf)와 확률 → χ²값으로 거꾸로 가는 함수(ppf, isf)로 나뉜다.

함수입력출력방향한 줄 의미
pdf(x, df)χ²값밀도(높이)x → 높이그 지점의 곡선 높이(확률 아님)
cdf(x, df)χ²값누적확률x → 확률P(X ≤ x), 왼쪽부터 누적 면적
sf(x, df)χ²값꼬리확률x → 확률P(X > x) = 1-cdf(x), 검정의 p-value로 직결
ppf(q, df)누적확률 qχ²값확률 → xcdf의 역함수, "누적확률 q가 되는 χ²는?"
isf(q, df)꼬리확률 qχ²값확률 → xsf의 역함수, "오른쪽 꼬리확률 q가 되는 χ²는?"
interval(a, df)중심확률 a(하한,상한)확률 → 구간중심 a를 포함하는 구간 — 비대칭!
stats(df,'mv')자유도(평균,분산)분포 → 요약값분포 전체의 평균·분산
카이제곱검정은 거의 항상 오른쪽 꼬리(단측) 검정이다. 관측값과 기대값의 차이가 클수록 χ²값이 커지므로, "크게 벗어났다"는 것은 항상 오른쪽 꼬리 방향이다. 그래서 sf()가 곧 p-value가 되는 경우가 대부분이다.

2pdf(x, df) — 확률밀도함수

2.1 원리

x=특정값 지점에서 곡선의 높이를 반환한다. 카이제곱분포는 비대칭이므로 최빈값(mode)이 평균(=df)보다 왼쪽에 있다.

\[ f(x;k)=\frac{1}{2^{k/2}\Gamma(k/2)}x^{k/2-1}e^{-x/2} \qquad \text{mode}=\max(k-2,\,0) \]

2.2 손계산 예제

[문제] df=6일 때 pdf의 최빈값(mode) 위치는? [Step1] mode = max(k-2, 0) = max(6-2, 0) = 4 [결론] df=6인 카이제곱분포는 χ²=4 지점에서 곡선이 가장 높다 (평균인 6보다 왼쪽)
Q. df=2인 카이제곱분포의 최빈값(mode)은?

3cdf(x, df) — 누적분포함수

0부터 x까지 곡선 아래 면적, 즉 P(X ≤ x)를 반환한다.

3.1 손계산 예제 (근사)

[문제] df=6에서 카이제곱분포표로 cdf(12.59,6)을 근사하시오 [Step1] 카이제곱표에서 χ²(0.05,6)=12.59를 찾음(상위 5% 지점) [Step2] 즉 P(X>12.59)=0.05 [결론] cdf(12.59,6) = 1-0.05 = 0.95

4sf(x, df) — 생존함수(p-value 직결)

x부터 오른쪽 끝까지의 면적, 즉 P(X > x). 카이제곱검정(적합도·독립성·동질성)은 항상 이 방향의 단측검정이므로, sf()가 그대로 p-value가 된다.

4.1 손계산 예제 — 독립성검정의 p-value

[문제] 카이제곱 학습서 3장 독립성검정 예제: χ²=12.5, df=1. p-value는? [Step1] p-value = P(X > 12.5) = sf(12.5, 1) [Step2] scipy 계산 결과 sf(12.5,1) ≈ 0.000407 [결론] p ≈ 0.0004 < .05 → H0 기각 (매우 강한 증거)
Q. 적합도검정에서 χ²=8.2, df=3일 때 p-value를 구하는 올바른 코드는?

5ppf(q, df) / isf(q, df) — 임계값 찾기

확률을 알 때 χ²값을 역산한다. 검정의 기각역 경계(임계값)를 구하는 표준 방법이다.

\[ \text{ppf}(1-\alpha,\,k) = \text{isf}(\alpha,\,k) = \chi^2_{(\alpha,\,k)} \]

5.1 손계산 예제

[문제] df=1, α=.05 단측검정의 임계값을 구하시오 [Step1] ppf(0.95, 1) 또는 isf(0.05, 1) — 둘 다 같은 값 [Step2] 카이제곱표에서 χ²(0.05,1) 확인 [결론] 임계값 = 3.841 (독립성검정 2×2표의 표준 임계값)
Q. isf(0.025, 5)와 같은 값을 반환하는 것은?

6interval(alpha, df) — 비대칭 신뢰구간

중심 확률 α를 포함하는 구간의 (하한, 상한)을 반환한다. 카이제곱분포는 비대칭이므로 t분포와 달리 하한·상한이 중심에서 대칭이 아니다.

하한까지의 거리는 짧고 상한까지의 거리는 길다 — 카이제곱분포가 비대칭임을 보여주는 시각적 증거다. 모분산검정의 양측검정 임계값(카이제곱 학습서 5장)이 바로 이 비대칭 interval의 하한·상한을 사용한다.
Q. 모분산검정(연속형)에서 양측 α=.05 검정을 할 때 하한·상한 임계값을 구하는 방법은?

7stats(df, moments='mv') — 분포 요약통계

\[ E(\chi^2_{(k)}) = k \qquad Var(\chi^2_{(k)}) = 2k \]

7.1 손계산 예제

[문제] df=10일 때 카이제곱분포의 평균과 분산은? [평균] E(X) = k = 10 [분산] Var(X) = 2k = 2*10 = 20 [결론] df가 커질수록 평균과 분산이 함께 커진다(t·F분포와 달리 df가 커져도 값이 특정 상수로 수렴하지 않음)
t분포나 F분포는 df가 커지면 분산이 특정 값(1 등)에 수렴하지만, 카이제곱분포는 df 자체가 분포의 위치와 퍼짐을 동시에 결정하므로 df가 커질수록 평균도 분산도 함께 커진다는 점이 다르다.
Q. df=15인 카이제곱분포의 분산은?

8Python(scipy)으로 실전 계산하기

# 7개 함수 한 번에 확인 from scipy.stats import chi2 df = 6 print("pdf(4,6) :", chi2.pdf(4, df)) # 최빈값 근처 밀도 print("cdf(8,6) :", chi2.cdf(8, df)) # P(X<=8) print("sf(8,6) :", chi2.sf(8, df)) # P(X>8) = p-value print("ppf(0.95,6) :", chi2.ppf(0.95, df)) # 단측 alpha=.05 임계값 print("isf(0.05,6) :", chi2.isf(0.05, df)) # 위와 동일한 값 print("interval(.95,6):", chi2.interval(0.95, df)) # 95% 구간(비대칭) print("stats(mv) :", chi2.stats(df, moments='mv'))
# 실전: 독립성검정 p-value를 sf로 직접 계산 observed_chi2, dof = 12.5, 1 p_value = chi2.sf(observed_chi2, dof) print(f"p-value = {p_value:.5f}")
# 실전: 모분산검정의 비대칭 양측 임계값 (카이제곱 학습서 5장과 연결) n, alpha = 20, 0.05 lower, upper = chi2.interval(1-alpha, df=n-1) print(f"기각역 경계: 하한={lower:.3f}, 상한={upper:.3f}")
chi2_contingency, chisquare 같은 고수준 함수는 내부적으로 sf()를 사용해 p-value를 계산한다. 저수준 함수를 이해하면 결과를 직접 검증하거나 커스텀 검정을 구현할 때 큰 도움이 된다.

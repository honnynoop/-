카이제곱검정(χ² Test) 완전정복

카이제곱 분포는 어디서 왔는가, 왜 그 형태를 가지는가부터 4가지 검정의 원리·손계산·실전 문제까지

0카이제곱 분포는 어디서 오는가

0.1 정의

표준정규분포 \(Z \sim N(0,1)\)를 따르는 서로 독립인 확률변수 \(Z_1, Z_2, \dots, Z_k\)가 있을 때, 이들의 제곱합은 자유도 k인 카이제곱분포를 따른다.

\[ \chi^2_{(k)} = Z_1^2 + Z_2^2 + \cdots + Z_k^2 = \sum_{i=1}^{k} Z_i^2 \]

즉 카이제곱분포는 "표준정규분포를 따르는 값들의 제곱합"이 만드는 분포다. 편차를 제곱하는 순간 값은 항상 0 이상이 되므로, 카이제곱분포는 음수를 갖지 않는 오른쪽 꼬리(right-skewed) 분포가 된다. 이 정의로부터 카이제곱검정이 "관측값과 기대값의 차이를 제곱해서 더하는" 형태를 갖는 이유가 자연스럽게 설명된다.

0.2 왜 이런 형태를 갖는가 — 자유도에 따른 형태 변화

0.3 평균과 분산

\[ E(\chi^2_{(k)}) = k \qquad Var(\chi^2_{(k)}) = 2k \]

자유도(df)가 곧 평균이라는 점이 핵심이다. 관측빈도와 기대빈도가 완전히 일치하면(우연한 오차만 존재) χ² 통계량은 대략 df 근처의 값을 가지며, df보다 훨씬 크면 "우연이라 보기 힘든 큰 차이"로 해석한다.

0.4 카이제곱검정의 공통 아이디어

카이제곱검정은 항상 같은 질문을 한다 — "관측된 값(O)이 기대한 값(E)에서 얼마나 멀리 떨어져 있는가?" 그 거리를 표준화해서(기대값 대비 상대적 크기로) 제곱해 모두 더한 것이 검정통계량이다.
\[ \chi^2 = \sum \frac{(O-E)^2}{E} \]

분모에 E가 들어가는 이유: 기대빈도가 큰 범주에서의 차이 10과 기대빈도가 작은 범주에서의 차이 10은 상대적 의미가 다르다. E로 나누어 "상대적 이탈 정도"로 표준화한다.

2적합도검정 (Goodness of Fit Test)

2.1 원리

하나의 범주형 변수가 사전에 가정한 이론적 비율(분포)과 일치하는지 검정한다. 예: 주사위가 공정한가(각 눈이 1/6씩), 특정 지역의 혈액형 비율이 전국 평균과 같은가.

\[ H_0: p_1=p_{01},\ p_2=p_{02},\ \dots,\ p_k=p_{0k} \qquad H_1: \text{적어도 하나는 다르다} \] \[ \chi^2 = \sum_{i=1}^{k}\frac{(O_i-E_i)^2}{E_i},\quad E_i = n \times p_{0i},\quad df=k-1 \]

2.2 손계산 예제

[문제] 주사위를 120번 던져 나온 눈: 1(15) 2(18) 3(24) 4(17) 5(22) 6(24). 공정한 주사위인가? (α=.05) [Step1] 기대빈도 E_i = 120 * (1/6) = 20 (모든 눈 동일) [Step2] 각 항: (15-20)²/20=1.25, (18-20)²/20=0.2, (24-20)²/20=0.8, (17-20)²/20=0.45, (22-20)²/20=0.2, (24-20)²/20=0.8 [Step3] χ² = 1.25+0.2+0.8+0.45+0.2+0.8 = 3.7 [Step4] df = 6-1 = 5, χ²(0.05,5) = 11.070 [결론] 3.7 < 11.070 → H0 기각 못함, 주사위는 공정하다고 볼 수 있음
Q. 범주가 5개인 적합도검정에서 자유도는?

3독립성검정 (Test of Independence)

3.1 원리

같은 모집단에서 뽑은 표본에 대해 두 범주형 변수가 서로 독립인지(관련이 없는지) 검정한다. 두 변수가 독립이라면, 결합확률은 각 주변확률의 곱과 같아야 한다는 확률의 성질을 이용한다.

\[ H_0: \text{두 변수는 독립이다} \quad(P(A\cap B)=P(A)P(B)) \qquad H_1: \text{독립이 아니다(관련이 있다)} \] \[ E_{ij} = \frac{(\text{i행 합계})\times(\text{j열 합계})}{\text{전체 합계}} \qquad df=(r-1)(c-1) \]

3.2 기대빈도 공식이 나오는 이유

두 변수가 독립이면 P(행=i, 열=j) = P(행=i) × P(열=j). 표본비율로 추정하면 P(행=i)≈행합계/전체, P(열=j)≈열합계/전체. 따라서 기대빈도 = 전체 n × P(행=i) × P(열=j) = (행합계×열합계)/전체합계가 된다.

3.3 손계산 예제 — 흡연 여부와 폐질환

[교차표] 폐질환有 폐질환無 행합계 흡연자 30 70 100 비흡연자 10 90 100 열합계 40 160 200 [Step1] E(흡연,有)=100*40/200=20, E(흡연,無)=100*160/200=80 E(비흡연,有)=100*40/200=20, E(비흡연,無)=100*160/200=80 [Step2] χ² = (30-20)²/20 + (70-80)²/80 + (10-20)²/20 + (90-80)²/80 = 100/20 + 100/80 + 100/20 + 100/80 = 5+1.25+5+1.25 = 12.5 [Step3] df=(2-1)(2-1)=1, χ²(0.05,1)=3.841 [결론] 12.5 > 3.841 → H0 기각, 흡연 여부와 폐질환 발생은 통계적으로 유의하게 관련 있음
2×2 교차표에서 기대빈도가 5 미만인 셀이 있으면 카이제곱 근사가 부정확해진다. 이 경우 Yates의 연속성 수정을 적용하거나(분자에서 0.5씩 빼줌), 표본이 아주 작으면 Fisher의 정확검정(Fisher's Exact Test)을 사용해야 한다.
\[ \text{Yates 수정: } \chi^2_{Yates} = \sum \frac{(|O-E|-0.5)^2}{E} \]
Q. 4×3 교차표에서 독립성검정의 자유도와, 기대빈도 5 미만 셀이 많을 때 대안으로 옳은 것은?

4동질성검정 (Test of Homogeneity)

4.1 원리 — 독립성검정과 무엇이 다른가

독립성검정

하나의 모집단에서 표본 1개를 추출 → 그 표본에서 두 변수(예: 성별, 선호도)를 동시에 측정. "두 변수가 관련 있는가?"

동질성검정

서로 다른 여러 모집단(집단)에서 각각 표본을 추출(행 합계가 사전에 고정) → 하나의 변수(범주)에 대한 분포 비율이 집단 간에 같은가?

수학적 계산 절차(기대빈도, χ² 통계량, 자유도)는 독립성검정과 완전히 동일하다. 차이는 표본추출 설계와 연구 질문의 관점뿐이다.

\[ H_0: p_{1j}=p_{2j}=\cdots=p_{rj}\ (\text{모든 집단에서 범주 비율이 동일}) \qquad df=(r-1)(c-1) \]

4.2 손계산 예제 — 지역별 제품 만족도 비율 비교

[문제] 세 지역(서울,부산,대구)에서 각각 100명씩 뽑아 만족/불만족 조사(행합계 고정=동질성검정) 만족 불만족 합계 서울 70 30 100 부산 55 45 100 대구 65 35 100 합계 190 110 300 [Step1] E(서울,만족)=100*190/300=63.33, E(서울,불만족)=100*110/300=36.67 E(부산,만족)=63.33, E(부산,불만족)=36.67 / E(대구,만족)=63.33, E(대구,불만족)=36.67 [Step2] χ² = (70-63.33)²/63.33 + (30-36.67)²/36.67 + (55-63.33)²/63.33 + (45-36.67)²/36.67 + (65-63.33)²/63.33 + (35-36.67)²/36.67 = 0.703+1.213+1.096+1.893+0.044+0.076 = 5.03 [Step3] df=(3-1)(2-1)=2, χ²(0.05,2)=5.991 [결론] 5.03 < 5.991 → H0 기각 못함, 지역 간 만족도 비율이 유의하게 다르다고 할 수 없음
Q. 세 개 병원에서 각각 정해진 인원을 뽑아 치료 성공/실패 비율이 병원마다 같은지 검정하려 한다. 이는 어떤 검정인가?

5모분산검정 (연속형 데이터)

5.1 원리

정규모집단에서 뽑은 표본의 분산 s²을 이용해 모분산 σ²이 특정 값과 같은지 검정한다. 카이제곱검정 중 유일하게 범주형이 아닌 개별 연속형 측정값을 직접 다룬다.

\[ \chi^2 = \frac{(n-1)s^2}{\sigma_0^2} \sim \chi^2_{(n-1)} \]

이 통계량이 카이제곱분포를 따르는 이유: 정규분포를 따르는 데이터에서 각 관측값의 표준화 편차 \((x_i-\bar x)/\sigma\)들의 제곱합이 위 0장에서 정의한 "표준정규 제곱합" 구조와 동일하기 때문이다(자유도는 표본평균 추정으로 1 감소하여 n-1).

5.2 손계산 예제

[문제] 부품 무게(g, 정규분포 가정) 표본 n=20, s²=12.5. "모분산=8"이 맞는지 α=.05 양측검정 [Step1] χ² = (n-1)*s² / σ0² = 19*12.5 / 8 = 237.5/8 = 29.69 [Step2] df=19, 하한 χ²(0.975,19)=8.907, 상한 χ²(0.025,19)=32.852 [Step3] 8.907 < 29.69 < 32.852 → 기각역 밖 [결론] H0 기각 못함 → 모분산이 8이 아니라고 할 근거 없음
모분산검정의 χ²분포는 좌우 비대칭이므로 두 집단 분산비교(F검정)와 달리 상한·하한 임계값을 따로 구해야 한다. 하한은 χ²(1-α/2, df), 상한은 χ²(α/2, df)를 사용한다.
Q. 정규모집단 표본 n=25, s²=18. "모분산=10"인지 검정할 때 χ² 통계량은?

6사용 시 전제조건과 흔한 오류

6.1 카이제곱검정의 전제조건

조건설명
독립적 관측치각 관측치(응답자 등)는 한 셀에만 속해야 함(중복 카운트 불가)
충분한 표본크기전체 표본 n이 충분히 커야 카이제곱 근사가 정확함
기대빈도 ≥ 5코크란(Cochran)의 규칙: 전체 셀의 80% 이상에서 E≥5, 어떤 셀도 E<1이면 안 됨
범주의 상호배타성범주가 겹치지 않고 모든 경우를 포함해야 함

6.2 기대빈도가 작을 때의 대안

범주 병합

의미상 가능하다면 빈도가 작은 인접 범주를 합쳐 기대빈도를 5 이상으로 만든다.

Fisher의 정확검정

2×2 표에서 표본이 작을 때 카이제곱 근사 대신 초기하분포를 이용해 정확한 p-value를 직접 계산한다.

6.3 흔한 해석 오류

① 인과관계로 오해: 독립성검정에서 유의한 결과가 나와도 "관련이 있다"는 것이지 "원인이다"는 아니다.
② 표본크기 민감성: n이 매우 크면 실질적으로 무의미한 작은 차이도 유의하게 나올 수 있다(통계적 유의성 ≠ 실질적 중요성). 이때는 Cramér's V 같은 효과크기 지표를 함께 본다.
③ 순서형 변수에 독립성검정만 사용: 순서가 있는 범주(예: 낮음/보통/높음)는 카이제곱검정이 순서 정보를 무시하므로, 경향성 검정(trend test) 등을 함께 고려하는 것이 좋다.
\[ \text{Cramér's V} = \sqrt{\frac{\chi^2}{n\times \min(r-1,\ c-1)}} \quad (0\sim1,\ \text{연관성의 강도}) \]

7Python(scipy)으로 실전 계산하기

7.1 적합도검정

# 주사위 예제 (2장) from scipy.stats import chisquare observed = [15, 18, 24, 17, 22, 24] expected = [20, 20, 20, 20, 20, 20] stat, p = chisquare(f_obs=observed, f_exp=expected) print(f"chi2={stat:.3f}, p={p:.4f}") # chi2=3.700, p=0.5934 → H0 기각 못함 (앞선 손계산과 일치)

7.2 독립성검정 / 동질성검정

# 흡연-폐질환 교차표 예제 (3장) import numpy as np from scipy.stats import chi2_contingency table = np.array([[30, 70], [10, 90]]) chi2, p, dof, expected = chi2_contingency(table, correction=False) print(f"chi2={chi2:.2f}, dof={dof}, p={p:.5f}") print("기대빈도:\n", expected) # correction=True (기본값)로 두면 2x2표에서 자동으로 Yates 연속성 수정 적용

7.3 모분산검정 (직접 구현)

# scipy에는 모분산검정 전용 함수가 없어 chi2 분포로 직접 계산 from scipy.stats import chi2 n, s2, sigma0_sq = 20, 12.5, 8 chi2_stat = (n - 1) * s2 / sigma0_sq lower, upper = chi2.ppf(0.025, df=n-1), chi2.ppf(0.975, df=n-1) print(f"chi2={chi2_stat:.2f}, 임계구간=({lower:.2f}, {upper:.2f})")
chi2_contingency는 기대빈도 행렬을 함께 반환하므로, 계산 후 기대빈도 5 미만 셀이 있는지 항상 확인하는 습관을 들이는 것이 좋다.
